# セッションチェックポイント

セッションの作業状態をローカルファイルに保存/復元する。
- Claude Code: セッションが飛んだ場合・新セッション開始時の復旧に使う
- Claude.ai: 新チャットに貼れる引き継ぎテキストも生成する

## トリガー

### 自動保存（AIが自律的に実行）
以下のタイミングで **ユーザーに確認せず自動で** チェックポイントを更新する:
- 大きなタスクが1つ完了したとき
- ツール呼び出し累計15回に達したとき
- ユーザーが「覚えておいて」「セーブ」「チェックポイント」と言ったとき
- `/compact` を推奨するタイミング（コンテキスト管理と連動）
- 画像を多く扱った会話で、セッション切替が予想されるとき

### 手動保存
ユーザーが「セーブして」「チェックポイント」「引き継ぎ」と言ったら即座に実行する。

## 保存先

- **Claude Code用**: `.claude/session-checkpoint.md`（上書き保存）
- **Claude.ai引き継ぎ用**: `.claude/session-handoff.md`（新チャットにコピペする用）

## Claude Code用チェックポイント（.claude/session-checkpoint.md）

以下のフォーマットで **上書き保存** する（追記ではない）:

```markdown
# Session Checkpoint

> このファイルはAIが自動更新する。新セッションで「前回の続きから」と言えば復旧に使われる。

Updated: {YYYY-MM-DD HH:MM}

## Current Task
{今やっている作業を1〜2行で}

## Progress
- [x] {完了済みのステップ}
- [ ] {未完了のステップ}

## Files Modified
- {変更したファイルパス}

## Key Context
- {案件名、クライアント名、重要な数値、URL等}
- {この作業で取得した重要データのサマリ}

## Next Steps
- {次にやるべきこと}
- {ユーザーへの確認事項（あれば）}
```

## Claude.ai引き継ぎ用（.claude/session-handoff.md）

新しいClaude.aiチャットの **最初のメッセージ** にコピペできるフォーマット。
ユーザーが「引き継ぎ作って」「新チャット用にまとめて」と言ったら生成する。

```markdown
# 前回のセッションからの引き継ぎ

## あなたの役割
Walkersの経営パートナー・リサーチャー・秘書AI。

## 前回やっていたこと
{作業内容を2〜3行で}

## 重要な背景情報
- {案件やクライアントに関する情報}
- {進行中の意思決定}
- {前回のセッションで得た重要なデータ}

## 未完了タスク
- {次にやるべきこと}

## 注意点
- {前回ハマったこと・避けるべきこと}
- 画像は1セッション5枚程度に抑える（2000pxエラー防止）
```

ポイント:
- **簡潔に**（Claude.aiの初回メッセージとして適切な長さ）
- **機密情報は書かない**
- **コピペしやすいよう、1つのmarkdownブロックにまとめる**

## 復元手順

新セッションでユーザーが以下のいずれかを言ったら復元する:
- 「前回の続きから」「復旧して」「チェックポイント読んで」

復元時の手順:
1. `.claude/session-checkpoint.md` を Read で読む
2. 内容をユーザーに要約して見せる
3. 「この状態から再開しますか？」と確認する
4. 必要なファイルを読み込んで作業を再開する

## 注意
- チェックポイントに **機密情報（APIキー・パスワード）は書かない**
- 大量のデータそのものではなく **サマリ** を書く（チェックポイント自体が肥大化しない）
- 1セッションにつき1チェックポイント（履歴は持たない、上書きのみ）
