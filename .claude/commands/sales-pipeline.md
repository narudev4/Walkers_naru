# 営業パイプライン更新・表示

トリガー: 「営業」「パイプライン更新」

## 概要
Gmail・Google Docs議事録・Notionから営業関連情報を収集し、`04_sales/pipeline.md` と `00_context/memories/facts.md` を最新状態に更新する。

## 利用ツール

| フェーズ | ツール | 用途 |
|---------|--------|------|
| Phase 1-1 | `gmail_search_messages` (Gmail MCP) | 直近14日の営業関連メール検索 |
| Phase 1-1 | `gmail_read_message` (Gmail MCP) | メール本文の詳細取得 |
| Phase 1-2 | `google_drive_search` (自作Google MCP) | 議事録・Geminiメモ検索 |
| Phase 1-2 | `google_docs_get` (自作Google MCP) | Docs本文取得 |
| Phase 1-3 | `gcal_list_events` (Google Calendar MCP) | 直近14日+今後7日の営業MTG取得 |
| Phase 1-4 | `API-post-search` (Notion MCP) | 営業関連データ検索 |
| Phase 1-5 | Glob + Read (built-in) | ローカル議事録・提案書確認 |
| Phase 1-6 | Read (built-in) | `pipeline.md` / `facts.md` 読み込み |
| Phase 3 | Edit (built-in) | `pipeline.md` / `facts.md` 更新 |

## 実行手順

### Phase 1: データ収集（並列実行）

1. **Gmail検索**: 直近14日間のメールを取得
   - `gmail_search_messages` で営業関連クエリ検索（最大30件）
   - 各メールの本文を `gmail_read_message` で読み込み
   - 営業関連メール（クライアント名・MTG・提案・見積もり等）を抽出

2. **Google Docs議事録検索**: Geminiメモ・議事録を確認
   - `google_drive_search` でキーワード検索（「議事録」「ミーティング」「Gemini」等）
   - ヒットしたDocsの内容を `google_docs_get` で取得

3. **Google Calendar検索**: 直近〜今後の営業MTGを確認
   - `gcal_list_events` で直近14日間+今後7日間の予定を取得
   - 営業関連のMTG（クライアント名を含む予定）を抽出

4. **Notion検索**: 営業関連データを検索
   - `mcp__notion__API-post-search` で「営業」「パイプライン」を検索
   - 該当するDBがあればデータを取得

5. **ローカルファイル検索**: 議事録・提案書を確認
   - `03_projects/` 内の最新の議事録・提案書をGlob+Readで確認
   - `output/minutes/` 内の最近の議事録を確認

6. **既存データ読み込み**:
   - `04_sales/pipeline.md` の現在の内容を確認
   - `00_context/memories/facts.md` の営業セクションを確認

### Phase 2: データ分析・統合

収集したデータから以下を特定:
- **新規リード**: まだパイプラインに未登録のクライアント
- **ステータス変更**: 進捗が進んだ/停滞した案件
- **次回アクション更新**: MTG日程・タスク期日の変更
- **完了・失注案件**: クローズすべき案件

### Phase 3: ファイル更新

1. **`04_sales/pipeline.md` を更新**:
   - 商談一覧を最新情報で上書き
   - 直近スケジュールテーブルを更新
   - 内部メモがあれば追記

2. **`00_context/memories/facts.md` の営業セクションを更新**:
   - サマリーテーブルを最新化
   - 直近MTGリストを更新

3. **更新日を記録**: 最終更新日を両ファイルに反映

### Phase 4: レポート出力

ユーザーにパイプラインの変更サマリーを報告:
- 新規追加された案件
- ステータスが変わった案件
- 直近1週間のMTGスケジュール
- 注意が必要な案件（期日切迫・長期停滞）

## パイプラインステージ

| ステージ | 説明 |
|---------|------|
| リード | 初回接触・問い合わせ |
| 商談中 | ヒアリング・提案準備中 |
| 提案済 | 提案書送付・比較検討中 |
| 契約手続き中 | 契約書ドラフト・条件交渉 |
| 準備中 | 受注確定・プロジェクト準備 |
| 進行中 | プロジェクト実行中 |
| 完了 | 納品・検収済み |
| 失注 | 不成立 |

## 出力フォーマット（pipeline.md）

```markdown
# 営業パイプライン

> 最終更新: YYYY-MM-DD
> ソース: Gmail・Google Docs議事録・Notion

---

## 商談一覧

### 1. クライアント名 / 担当者名
- **ステータス**: ステージ名
- **案件内容**: 概要
- **経緯**: 時系列メモ
- **次回アクション**: 日付・内容
- **優先度**: 高/中/低

---

## 直近スケジュール（営業MTG）

| 日付 | 時間 | クライアント | 内容 |
|------|------|------------|------|

---

## 内部メモ
- 社内戦略MTGの内容等
```

## ルール
- 金額は日本円表示
- 期日が1週間以内の案件はアラートを出す
- 2週間以上動きのない案件は停滞として注意喚起する
- 既存の案件情報は上書きではなく経緯を追記する形で更新する
- 推測では進めず、メール・議事録に根拠がある情報のみ記録する
