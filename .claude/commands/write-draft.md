# 記事下書き生成

トリガー: 「記事を書いて」「下書き」

## 利用するツール

| ソース | ツール | 用途 |
|--------|--------|------|
| Web検索 | `WebSearch` | テーマに関する最新情報・参考記事を収集 |
| Webページ読み込み | `WebFetch` | 参考記事の詳細を取得 |
| ローカル | `Glob` + `Read` | 過去の記事・関連資料を確認 |
| 保存 | `Write` ツール | 下書きを `output/articles/` に保存 |

## 実行手順

1. ユーザーからテーマ・ターゲット読者・文字数・トーンをヒアリングする
2. **情報収集**（並列実行）:
   - `WebSearch(query="[テーマ] [関連キーワード]")` で最新情報を収集（2〜3クエリ）
   - `WebFetch` で有用な記事の詳細を取得
   - `Glob` + `Read` でローカルの関連資料（`output/articles/`, `06_learning/`）を確認
3. 記事の構成案を作成し、ユーザーに確認する
4. 承認後、下書きを執筆する
5. `Write` ツールで `output/articles/YYYY-MM-DD_[テーマ].md` に保存して報告する

## 出力先
`output/articles/YYYY-MM-DD_[テーマ].md`

## 記事テンプレート

```markdown
# [タイトル]

## リード文
[読者の関心を引く導入文 3-5行]

## 本文
### [見出し1]
[内容]

### [見出し2]
[内容]

### [見出し3]
[内容]

## まとめ
[要点の整理とCTA]

---
生成日: YYYY-MM-DD
テーマ: [テーマ]
想定読者: [ターゲット]
文字数: 約[X]文字
```

## ルール
- 構成案の段階でユーザーの承認を得る
- SEOを意識した見出し構成にする
- 専門用語は必要に応じて解説を入れる
