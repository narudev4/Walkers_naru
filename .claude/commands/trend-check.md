# トレンド調査

トリガー: 「トレンド調べて」

## 利用するツール

| ソース | ツール | 用途 |
|--------|--------|------|
| Web検索 | `WebSearch` | キーワードで最新トレンド情報を収集（複数クエリを並列実行） |
| Webページ読み込み | `WebFetch` | 検索結果の記事詳細を取得 |
| ローカル | `Glob` + `Read` | 過去のトレンドレポート（`output/trends/`）を確認 |

> **Note**: X (Twitter) MCP は未導入。SNS情報は `WebSearch(query="site:x.com [キーワード]")` で代替する。

## 実行手順

1. ユーザーからテーマ・業界・キーワードをヒアリングする
2. **Web検索**（並列実行）:
   - `WebSearch(query="[キーワード] トレンド 2026")` でトレンド情報を収集
   - `WebSearch(query="[キーワード] 最新動向")` で別角度から収集
   - `WebSearch(query="site:x.com [キーワード]")` でSNS上の話題を収集
3. **詳細取得**: 有用な記事は `WebFetch(url="...", prompt="...")` で詳細を取得
4. 収集した情報を整理・分析する
5. レポートを生成して保存する

## 出力フォーマット

`output/trends/YYYY-MM-DD_[テーマ].md` に保存：

```markdown
# トレンドレポート: [テーマ]
生成日: YYYY-MM-DD

## サマリー
[3行以内の要約]

## 主要トレンド
1. [トレンド1]: [説明]
2. [トレンド2]: [説明]
3. [トレンド3]: [説明]

## SNSの反応
- [注目の投稿・意見]

## Walkersへの示唆
- [事業への影響・活用可能性]

## 情報ソース
- [URL/出典]
```

## ルール
- 情報ソースを必ず明記する
- 事実と推測を区別する
- Walkersの事業に関連する示唆を必ず含める
