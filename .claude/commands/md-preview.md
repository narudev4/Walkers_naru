# Markdownプレビュー

`mo`（CLIマークダウンビューワー）でMarkdownファイルをブラウザ表示する。

## 入力

$ARGUMENTS にMDファイルのパス（複数可・スペース区切り）が渡される。省略時はユーザーに聞く。

## 手順

```bash
~/bin/mo <ファイル1.md> [ファイル2.md ...]
```

これだけ。GFM・シンタックスハイライト・Mermaid対応のプレビューがブラウザで開く。

### 複数ファイル

```bash
# 2ファイルをタブ切り替えで表示
~/bin/mo file1.md file2.md

# 既にサーバーが起動中なら追加でファイルを開ける
~/bin/mo file3.md
```

### サーバー管理

```bash
~/bin/mo --status     # 稼働中サーバー一覧
~/bin/mo --shutdown   # シャットダウン
```

### オプション

- `--no-open`: ブラウザを自動で開かない（cmux連携時に使用）
- `-p <port>`: ポート指定（デフォルト: 6275）
- `--target <name>`: グループ名を付けて分類
