# WebFetch フォールバック

> `WebFetch` ツールが失敗した時に Read する。

## 失敗パターン

- 403 Forbidden（Bot ブロック）
- タイムアウト
- JS 必須ページで空のコンテンツが返る
- ログインが必要なページ

## 対応

`browser-use` スキルを起動して実ブラウザから取得する。

```
/browser-use
```

スキルが受け取る情報:
- 取得したい URL
- 取得したい情報の種類（テキスト全文、特定要素、スクリーンショット等）
- ログインが必要なら認証情報の所在

## 注意

- `browser-use` は実際に Chrome を起動するので時間がかかる
- 1〜2 ページの取得なら問題ないが、大量取得は別の手段（API、スクレイピングスクリプト）を検討する
- ログイン情報は `credentials/` 配下のファイルから取得する（直接ハードコードしない）
