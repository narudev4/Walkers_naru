# Gmail スレッド返信下書き作成

トリガー: 「スレッド返信」「返信下書き」「メール返信」「返信して」

引数: $ARGUMENTS（返信対象の指定 — メールの送信者名、件名、スレッドID等 + 返信内容の指示）

## 概要
Gmailのスレッドに返信する形で下書きを作成する。通常の `gmail_create_draft` ではスレッドに紐づかない独立した下書きが作られるが、このスキルでは `google_gmail_create_reply_draft`（自作Google MCP）を使ってスレッド内に返信ドラフトを配置する。

## 前提条件
- 自作Google MCP（`05_development/mcp-google/`）がGmailスコープで認証済みであること
- 未認証の場合は「`cd 05_development/mcp-google && node auth.js` を実行してGmail権限を再認証してください」と案内する

## 実行手順

### Step 1: 返信対象のスレッドを特定する

ユーザーの指示（$ARGUMENTS）から返信対象を特定する:

1. **スレッドID / メッセージID が指定されている場合**
   → そのまま Step 2 へ

2. **送信者名・件名・キーワード等が指定されている場合**
   → マネージドコネクタの `gmail_search_messages` で検索する
   - 検索クエリ例: `from:xxx@example.com`, `subject:提案書`, `xxx AND yyy`
   - 検索結果が複数ある場合はユーザーに選択させる

3. **曖昧な指定の場合**
   → ユーザーにヒアリングして絞り込む（「どのメールへの返信ですか？」）

### Step 2: スレッド内容を確認する

`google_gmail_get_thread` でスレッド全体を取得し、会話の流れを把握する。
- スレッド内のメッセージ一覧（送信者・日時・件名・スニペット）をユーザーに提示
- 返信先の最新メッセージを特定する（通常はスレッド最後のメッセージ）

必要に応じて `google_gmail_get_message` で返信先メッセージの本文も取得する。

### Step 3: 返信内容を確定する

1. **ユーザーが返信内容を指定している場合**
   → その内容をベースに返信文面をドラフトする

2. **返信内容が未指定の場合**
   → 「どのような返信にしますか？」とヒアリングする

3. **返信文面のドラフト**
   - ビジネスメールとして適切なトーンで作成
   - 必要に応じて元メッセージの引用を含める
   - ユーザーに最終確認を求める: 「この内容で下書きを作成しますか？」

### Step 4: スレッド返信ドラフトを作成する

`google_gmail_create_reply_draft` を呼び出す:

```
ツール: google_gmail_create_reply_draft（自作Google MCP）
パラメータ:
  - message_id: 返信先メッセージのID
  - body: 返信本文
  - content_type: "text/plain"（HTML版は "text/html"）
  - reply_all: 全員返信の場合 true
  - cc: 追加CCがあれば指定
```

**重要**: マネージドコネクタの `gmail_create_draft` ではなく、自作MCPの `google_gmail_create_reply_draft` を使うこと。これによりスレッド内に返信として配置される。

### Step 5: 結果を報告する

- ドラフトID、件名、宛先を表示
- 「Gmailの下書きフォルダから確認・送信できます」と案内
- ユーザーが希望すれば `google_gmail_send_draft` で即送信も可能

## オプション: そのまま送信

ユーザーが「送信して」「送って」と言った場合:
1. `google_gmail_send_draft` でドラフトを即送信
2. 送信完了を報告

## ルール

- **返信文面は必ずユーザーに確認してから下書き作成する**（誤送信防止）
- **送信は明示的な指示がある場合のみ行う**
- 返信先のメッセージが特定できない場合は推測せず、ユーザーにヒアリングする
- reply_all は明示的に「全員に返信」と言われた場合のみ true にする
- CCの追加・変更はユーザーの指示に従う
