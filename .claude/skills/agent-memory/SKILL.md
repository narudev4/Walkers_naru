# エージェントメモリ保存

トリガー: 「覚えておいて」

## 実行手順

1. ユーザーの発言内容を分析し、適切なメモリファイルを判定する
2. 該当ファイルに追記する
3. 保存した内容をユーザーに確認する

## 振り分けルール

| 内容の種類 | 保存先 | 例 |
|-----------|--------|-----|
| 事実・データ | `00_context/memories/facts.md` | 売上、契約情報、技術スタック、連絡先 |
| 好み・スタイル | `00_context/memories/preferences.md` | コミュニケーションスタイル、作業習慣、ツールの好み |
| 意思決定 | `00_context/memories/decisions.md` | 決定事項、その理由、背景 |

## 記録フォーマット

```markdown
### YYYY-MM-DD
- [記録内容]
```

## ルール
- 既存の記録と重複する場合は更新する（二重登録しない）
- 機密性の高い情報（パスワード等）は保存しない
- 保存後、何をどこに保存したかをユーザーに報告する
