# タイトル案生成

トリガー: 「タイトル案」

## 実行手順

1. ユーザーからテーマ・ターゲット読者・媒体をヒアリングする
2. 5パターン以上のタイトル候補を生成する
3. 各タイトルの狙い・特徴を簡潔に説明する

## 生成パターン（最低5種類）

| パターン | 特徴 | 例 |
|---------|------|-----|
| 直球型 | ストレートに価値を伝える | 「〇〇の完全ガイド」 |
| 疑問型 | 読者の疑問を代弁する | 「なぜ〇〇は△△なのか？」 |
| 数字型 | 具体的な数字で引きつける | 「〇〇を変える7つの方法」 |
| メリット型 | 得られる利益を強調する | 「〇〇で売上が2倍になった理由」 |
| 比較型 | 対比で興味を引く | 「〇〇と△△、どちらが正解か」 |

## 出力フォーマット

```
### タイトル候補

1. **[タイトル]** — 直球型: [狙いの説明]
2. **[タイトル]** — 疑問型: [狙いの説明]
3. **[タイトル]** — 数字型: [狙いの説明]
4. **[タイトル]** — メリット型: [狙いの説明]
5. **[タイトル]** — 比較型: [狙いの説明]

おすすめ: [番号] — [理由]
```

## ルール
- 最低5パターンを提示する
- 各タイトルの狙い・特徴を明記する
- おすすめを1つ提示し、その理由を説明する
