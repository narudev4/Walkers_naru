# 鳳汰スタイルガイド（note-rewrite）

このファイルは山口鳳汰さんの編集判断軸を蓄積する。`note-rewrite` SKILL.md のフロー骨格から分離した「判断系」の中身。
ゴールは「鳳汰さんを呼ばずに鳳汰さんレベルの成果物が出せる状態」。FBごとに即追記。

## 判断軸（明文ルール）

### 文体・トーン
- noteは「だである調」（自分の主張を出す場）
- 切り口を変えた瞬間に刺さる（AI→Claude Code 等）

### 構成
- H2配下の並列項目はH3に揃える（目次が綺麗・YouTube流用しやすい）
- アイキャッチは「最低限見やすければOK」。凝りすぎない
- 末尾は CTA だけ残し、蛇足な「まとめ」は削る

### 表現の冗長性カット
- 装飾の点記号は冗長になりがち。極力使わない
- **同じ修飾語を 2 回目に出すときは省く**（例: 「LP + デモ動画」→「LP + デモ」、「Claude Code・ノーコード」→「ノーコード」。直前のパラグラフで説明済み or 記事全体の文脈で明らかな修飾語は冗長になる）

### 切り口リライト時の論点再評価（重要）
- **切り口で前提が変わる論点は削除/書き換える**（元記事/元動画の論点を盲目的に踏襲せず、Phase 2 初稿生成で毎章チェック）
- **論点を削ったら本文・末尾ステップの残響も削除**（章だけ消しても文中・まとめに残ると整合性が崩れる）
- **ただし上記2項目は Phase 2 初稿生成の段階で適用する**。Phase 3 で鳳汰の修正版が届いたら、その内容を **そのまま** 採用する。Claude が判断軸の整合性のために追加で本文を削る/書き換えるのは **禁止**。整合性が気になる箇所は naru/鳳汰に申し送り、指示を待つ（2026-05-13 越権事案より）
