# STEP 7: YouTube投稿 — 手動手順

HeyGen でダウンロードした動画を YouTube にアップロードする。全て手動作業。

## 手順（5ステップ）

### 1. 動画アップロード

- YouTube Studio（https://studio.youtube.com）を開く
- 「作成」→「動画をアップロード」
- ファイル: HeyGen からダウンロードした動画を選択

### 2. 概要欄設定

- STEP 5.5 で生成済みの概要欄テンプレート全文を概要欄に貼り付け
- テンプレートにはクリップボードに既にコピー済み（Ctrl+V / Cmd+V で貼り付け可）
- 概要欄の内容: タイトル、要約、【目次】（実音声ベースのチャプター）、関連リンク等

### 3. サムネイル

- 別途用意したサムネイル画像をアップロード

### 4. ⚠ 「改変されたコンテンツ」にチェック（CRITICAL）

- 「詳細」タブの下部にある「改変されたコンテンツ」セクション
- 「この動画はリアルに見えるように改変または合成されたコンテンツですか？」
  → **「はい」にチェックを入れる**
- ⚠ AIアバター（HeyGen）を使用しているため必須。チェックしないと YouTube のポリシー違反になる可能性

### 5. 公開設定

- まず**「非公開」**でアップロード
- 動画を確認後、問題なければ「公開」に変更

## 完了後

- 投稿が完了したら「完了」と伝える
- パイプライン終了
