# STEP 6: HeyGen動画生成 — 手動パート

自動化部分（PPTXアップロード・音声アップロード・アバター配置・BGM設定値の詳細）は `/yt-heygen` に完全に委譲する。
このファイルには**手動作業のみ**を記載する。

## 前提

- HeyGen にログイン済み・Chrome の `walker-s.co.jp` プロファイルを使用
- `/yt-heygen {slug}` の自動化コマンド（Phase 0 / Phase 1+2）は別途実行する

## 手動作業（5項目）

### 1. PPTXアップロード時の設定確認

- Phase 0 コマンド実行後、HeyGen エディタが自動で開く
- ⚠ アップロード時「**スライドの内容を編集可能な要素としてインポート**」が出たら**必ずOFF**にする

### 2. アバター選択（初回のみ）

2回目以降は前回設定が引き継がれる場合あり。初回だけ以下を設定:

| 項目 | 値 |
|------|-----|
| アバター | `<担当者名>鳳汰(背景リアル&スーツ見えるver)` |
| レイアウト | 円 |
| ズーム | 139% |
| モーションエンジン | アバター IV |
| 適用 | 「既存のアバターを置き換え」→「選択」で全シーン適用 |

### 3. 背景BGM追加

- 画面上部または左メニューから「Background Music」を選択
- BGMジャンル: Corporate / Upbeat系
- **Volume: 3%**（ナレーションが聞こえなくなるので必ず下げる）
- **Loop music: ON**

### 4. プレビュー確認

いくつかのシーンを再生して以下をチェック:

- [ ] スライドが正しく表示されているか
- [ ] アバターが右上に配置されているか（200×200・右上角）
- [ ] 音声がスライドと一致しているか
- [ ] BGMが小さく流れているか

### 5. 生成ボタン押下

- 右上の「✓ 生成」ボタン → Quality + 1080p → 生成開始
- 生成に2〜4時間かかる。放置OK
- 完成後、動画をダウンロードして STEP 7 に進む

## トラブル時

- 音声アップロードのずれ・複製 → yt-heygen の「手動で音声を先にアップしない」ルールを破っていないか確認
- DOM構造エラー → HeyGen UI変更の可能性。yt-heygen スクリプトの修正が必要
- その他の自動化エラー → `/yt-heygen` の「安全策」「レジューム」セクション参照
