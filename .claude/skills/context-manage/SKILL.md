# コンテキスト管理スキル

会話のコンテキスト容量を診断し、セッション継続のための最適化アクションを提案する。

## 利用ツール

| ステップ | ツール | 用途 |
|---------|--------|------|
| 診断 | （ツール不使用） | 会話状態を内部的に評価 |
| 推奨 | `/compact` (Claude Code組み込みコマンド) | 会話履歴の圧縮 |

> **Note**: `/compact` はスキルファイルではなくClaude Codeの組み込みコマンド。ユーザーがチャット欄で直接 `/compact` と入力して実行する。

## 実行手順

### Step 1: 現在の会話状態を診断
以下を評価して報告する:
- 現在の会話ターン数（おおよそ）
- 重いツール呼び出しの有無（大量のデータを返すAPI呼び出し等）
- サブエージェント使用の有無（Taskツール経由の並列処理）

### Step 2: 即時アクション
ユーザーに以下を提示する:

```
⚠️ コンテキスト管理レポート

📊 会話状態: [軽量 / 中程度 / 重い / 危険]
🔄 推奨アクション:

1. /compact を実行してください（会話履歴を圧縮します）
2. 新しいタスクは新セッションで開始を推奨します

💡 ヒント:
- 大きなファイルの全文読み込みを避ける（offset/limitで部分読み込み）
- Taskツール（サブエージェント）で重い処理を分離する
- 1セッション = 1テーマが最も安定
```

### Step 3: 根本対策の提案（必要な場合のみ）
繰り返し溢れる場合は以下を提案:
- `.mcp.json` から未使用MCPサーバーの削除
- CLAUDE.md のスリム化（詳細はスキルファイルに委譲）
- MEMORY.md の整理（古い案件情報のアーカイブ）

## 判断基準

| 状態 | 目安 | アクション |
|------|------|-----------|
| 軽量 | ターン10未満、単純な会話 | 継続OK |
| 中程度 | ターン10-20、ツール呼び出し多数 | `/compact` を推奨 |
| 重い | ターン20+、大量データ取得あり | `/compact` を強く推奨 |
| 危険 | ツール結果が何度も大きい、エラー兆候 | `/compact` 必須 + 新セッション推奨 |
