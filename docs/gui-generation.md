# 動的GUI生成ルール

AIは以下の場面で**自分の判断で**GUIを生成し、ユーザーにリンクを提示してよい。「GUIで」と言われるのを待つ必要はない。

## 自動生成すべき場面

- **データが5件以上**のリスト・一覧を提示するとき
- **比較・選択**をユーザーに求めるとき（カード/テーブル）
- **ステータス管理**を伴うデータの確認・更新（カンバン）
- **数値データ**の報告（チャート・メトリクスカード）
- **スケジュール・タイムライン**の共有（カレンダー）
- **ユーザーに入力・編集してほしい**データ（フォーム）
- **複雑な構造**のデータ説明（ツリー・カード・テーブル）

## 生成方法（高速）

1. `gui-core.js` / `gui-style.css` の Read は不要（`output/gui/` に配置済み、外部参照で読み込まれる）
2. データをJSON化し、`<link href="gui-style.css">` + `<script src="gui-core.js">` で外部参照するHTMLを生成
3. `output/gui/{name}.html` に Write で保存
4. ブラウザで開くURLを案内
5. 詳細手順は `.claude/commands/gui.md` 参照

## 判断基準

- テキストで十分伝わる場合（1〜2行の回答）→ GUI不要
- 「ちょっと見づらいな」と感じるデータ量・構造 → GUI生成を検討
- ユーザーにデータを**編集してほしい**場合 → 積極的にGUI生成
