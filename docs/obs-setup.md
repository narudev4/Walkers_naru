# OBS Studio セットアップ手順（meeting-transcribe 連携用）

> 目的: ローカル録画で **画面 + マイク + システム音（相手の声）** を**別トラック**で録音し、`meeting-transcribe` スキルに食わせる。設定は1回だけ。実運用は `Cmd+Option+R` 1キーで録画開始/停止。

## ゴール

- 全 MTG プラットフォーム（Meet/Zoom/Teams/対面）で **統一録画**
- 録画開始/停止は **ホットキー1キー**（毎回画面選択しなくていい）
- マイク=Track 1, システム音=Track 2 で **別録音**（話者分離精度UPに直結）
- 保存先固定 `~/Movies/OBS/`、ファイル名は自動で日時付き

所要時間: 初回 30〜40分。次回以降はゼロ。

---

## Phase 1: インストール（5分・自動化済み）

```bash
brew install --cask obs
```

→ Claude Code がバックグラウンドで実行中。完了通知を待つ。

## Phase 2: 初回起動と権限許可（3分・必須）

1. `/Applications/OBS.app` を起動
2. 初回ウィザード「自動構成ウィザード」が出たら **「キャンセル」**（手動で設定する）
3. **macOS の権限を3つ許可**:
   - システム設定 → プライバシーとセキュリティ → **画面収録** → OBS をON
   - システム設定 → プライバシーとセキュリティ → **マイク** → OBS をON
   - システム設定 → プライバシーとセキュリティ → **アクセシビリティ** → OBS をON（ホットキー用）
4. OBSを **一度再起動**（権限反映のため）

## Phase 3: シーン作成（10分）

OBSのデフォルトには空のシーン「シーン」が1つある。これを使う。

### 3-A. ディスプレイキャプチャ（画面全体）

1. 画面下「ソース」パネル → `＋` ボタン
2. `macOS スクリーンキャプチャ` を選択
3. 名前: `画面全体`
4. プロパティ画面:
   - 方法: **ScreenCaptureKit**
   - キャプチャタイプ: **Display Capture**（画面全体）
   - ディスプレイ: メインディスプレイ
   - **「アプリケーション音声を取り込む」をON** ← これがシステム音録音の鍵
5. OK

### 3-B. マイク音声

通常はデフォルトで「マイク/補助音声」が音声ミキサーに追加済み。確認:
1. 画面下「音声ミキサー」パネルにマイクが表示されているか
2. 表示されていなければ: 画面下「ソース」→ `＋` → `音声入力キャプチャ` → 名前 `マイク` → デバイス: MacBookのマイク
3. 喋ってメーターが動くことを確認

### 3-C. オーディオトラックの分離設定（重要）

マイクとシステム音を **別トラックで録音** する設定:

1. メニューバー: `OBS` → `設定`
2. 左側 `出力`
3. 上部タブ `録画`
4. **`音声トラック`** の項目で:
   - **Track 1**: チェック（マイク用）
   - **Track 2**: チェック（システム音用）
5. 設定を `適用`

次にミキサーごとのトラック割当:
1. 音声ミキサー → マイク横の歯車 → `オーディオの詳細プロパティ`
2. **マイク** の行:
   - Track 1: ✓
   - Track 2: -
3. **画面全体（アプリケーション音声）** の行:
   - Track 1: -
   - Track 2: ✓
4. 閉じる

→ これで MTG 録画後、`.mp4` ファイル内に **音声2トラックが分離して入る**。`meeting-transcribe` の v2 で話者分離に使う。

## Phase 4: 出力設定（5分）

メニュー `OBS` → `設定` → `出力`:

### 録画タブ
- 種別: `標準`
- 録画ファイルのパス: **`/Users/naru/Movies/OBS`**（フォルダが無ければ作る: `mkdir -p ~/Movies/OBS`）
- 録画フォーマット: **`mp4`**（互換性最高、ffmpeg で扱いやすい）
- エンコーダ: `Apple VT H.264 ハードウェア`（M系チップで高速、CPU負荷低い）
- 録画品質: `高品質、ファイルサイズ中`（議事録なら十分）

### 音声タブ
- サンプリングレート: `48 kHz`
- チャンネル: `ステレオ`

設定を `適用` → `OK`。

## Phase 5: ホットキー設定（5分）

メニュー `OBS` → `設定` → `ホットキー`:

1. **`録画開始`** の入力欄をクリック → `Cmd+Option+R` を押下
2. **`録画終了`** の入力欄をクリック → `Cmd+Option+S` を押下
3. 設定を `適用` → `OK`

→ これで OBS がフォアグラウンドでなくても、グローバルに `Cmd+Option+R` で録画開始、`Cmd+Option+S` で停止できる。

## Phase 6: ログイン時自動起動（2分）

OBS をメニューバー常駐させ、ログイン時に起動:

1. システム設定 → 一般 → ログイン項目
2. `+` → `/Applications/OBS.app` を追加
3. **「バックグラウンドのみ」のチェック**を入れる（ドックに表示しない）
4. OBS 側: メニュー `OBS` → `設定` → `一般` → **「OBS Studio が最小化されたときにシステムトレイに表示する」を ON**

## Phase 7: テスト録画（5分）

1. **ホットキー `Cmd+Option+R`** を押す
2. メニューバーの OBS アイコンが録画中表示になる
3. 適当な動画（YouTube とか）を再生して、独り言でマイクに喋る（30秒〜1分）
4. **`Cmd+Option+S`** で停止
5. `~/Movies/OBS/` に `.mp4` ができているか確認
6. プレビューで再生し、**マイクの声＋システム音（YouTube音声）が両方聞こえる**ことを確認

### トラック分離の確認

```bash
ffprobe ~/Movies/OBS/<最新の録画>.mp4 2>&1 | grep -E "Stream|Audio"
```

`Audio` ストリームが **2本**ある（Track 1=マイク, Track 2=システム音）ことを確認。

## Phase 8: meeting-transcribe との連携テスト

テスト録画ファイルを `meeting-transcribe` に食わせて、議事録が出るか確認:

1. Claude Code で「テスト録画から議事録作って」と頼む
2. Phase 1 ヒアリングで:
   - 録画ソース: `~/Movies/OBS/<最新>.mp4`
   - 案件: `anything`（テスト用）
   - 会議名: `obs-setup-test`
   - 参加者: `naru`
   - 日時: 今日の日付
3. Phase 4 文字起こしが走る
4. Phase 7 議事録が `03_projects/anything/minutes/{日付}_obs-setup-test/` に出る

→ 出れば本番運用準備完了。

## 実運用の流れ（セットアップ後）

1. MTG 入る前: **`Cmd+Option+R`**（OBS は常駐済みなので即録画開始）
2. MTG 中: 普通に話す
3. MTG 終了: **`Cmd+Option+S`**
4. 録画ファイルは `~/Movies/OBS/YYYY-MM-DD HH-MM-SS.mp4` に保存される
5. Claude Code で「さっきの録画から議事録作って」と頼む

## トラブルシュート

| 症状 | 対処 |
|---|---|
| 録画ボタンを押しても始まらない | macOS の画面収録権限を確認 → OBS を再起動 |
| マイクが録れていない | OBS の `設定` → `音声` → マイク入力デバイス確認、音声ミキサーで赤メーターが動くか |
| システム音が録れていない | ディスプレイキャプチャの `アプリケーション音声を取り込む` がONか、ScreenCaptureKit が選択されているか |
| トラックが1本にしかならない | 出力設定で Track 1, 2 両方チェック、音声詳細プロパティで各ソースが正しいトラックに割当られているか |
| ホットキーが効かない | アクセシビリティ権限を確認、OBS 起動中か |
| 動画が重い | エンコーダを `Apple VT H.264 ハードウェア` に、品質を「中」に下げる |

## 既知の制約

- Apple Silicon（M系）が前提（Intel Mac は別エンコーダ設定が要る）
- ScreenCaptureKit は macOS 13+（naru は macOS 26 なので問題なし）
- ストレージ: 1時間のMTGで約 500MB〜1GB（H.264 中品質）。月10回のMTGで 5〜10GB
- 録画動画は `meeting-transcribe` の規約どおり、`03_projects/{案件}/minutes/` 配下にはコピーせず、参照リンクのみ記載（S3 同期外）
