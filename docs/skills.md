# スキル索引

> この文書は **トリガー語 → スキル名** のマッピング索引です。
> スキルの実装・手順は各 `.claude/skills/<name>/SKILL.md` 側にあります（Skillツール起動時にハーネスが自動ロード）。

## 運用ルール

- トリガー語が含まれていれば**文脈を問わず即座に**Skillツールで該当スキルを起動する
- 「何をしますか？」等の聞き返しは禁止。該当語がない場合のみ聞き返し可
- 手動代替禁止。スキルが対応する領域で直接ツールを叩いてはならない
- Google Chat経由（`claude -p`）はSkillツール非対応のため、意図を直接ツールで実行する
- 重複名（例: `browser-use`）はプロジェクト版 `.claude/skills/` を優先する
