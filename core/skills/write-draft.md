# 記事下書き生成

トリガー: 「記事を書いて」「下書き」

## 実行手順

1. ユーザーからテーマ・ターゲット読者・文字数・トーンをヒアリングする
2. テーマに関する情報をWeb検索で収集する
3. 記事の構成案を作成し、ユーザーに確認する
4. 承認後、下書きを執筆する
5. 保存して報告する

## 出力先
`output/articles/YYYY-MM-DD_[テーマ].md`

## 記事テンプレート

```markdown
# [タイトル]

## リード文
[読者の関心を引く導入文 3-5行]

## 本文
### [見出し1]
[内容]

### [見出し2]
[内容]

### [見出し3]
[内容]

## まとめ
[要点の整理とCTA]

---
生成日: YYYY-MM-DD
テーマ: [テーマ]
想定読者: [ターゲット]
文字数: 約[X]文字
```

## ルール
- 構成案の段階でユーザーの承認を得る
- SEOを意識した見出し構成にする
- 専門用語は必要に応じて解説を入れる
