# 日程調整

トリガー: 「日程調整」「スケジュール調整」「空いてる日出して」「候補日出して」

引数: $ARGUMENTS（相手名、希望時間帯、期間などの自由テキスト）

## 実行手順

### Step 1: ヒアリング（引数がない場合）
以下を確認する:
- **相手**: 誰との日程調整か
- **希望時間帯**: 朝 / 午後 / 夕方 / 終日 など（デフォルト: 終日）
- **期間**: いつからいつまでの範囲で探すか（デフォルト: 翌週〜再来週の平日）
- **所要時間**: 何分のMTGか（デフォルト: 60分）
- **備考**: 「仕事終わり前」等の相手の制約

### Step 2: カレンダー取得
**必ず両方のカレンダーを取得する**（片方だけ見て提案しない）:
1. 仕事カレンダー: `primary`（walker-s.co.jp）
2. 個人カレンダー: `<YOUR_EMAIL>`

### Step 3: 空き枠抽出
各日について以下を実行する:
1. 両カレンダーの予定を時系列にマージする
2. 希望時間帯内で、所要時間分の空きがある枠を抽出する
3. **バリデーション**: 抽出した各枠について、既存予定との被りがないか1つずつ確認する

#### バリデーションルール
- 空き枠の開始〜終了の間に、既存の予定が1つでも存在したらその枠はNG
- `transparency: "transparent"` の予定（コンサータ摂取等のリマインダー）は無視してOK
- 「連絡を返す」「睡眠」等の定型タスクは**ブロックとして扱う**（勝手に移動しない）

### Step 4: 候補フォーマット
相手の制約に応じてフォーマットを変える:

#### パターンA: 相手の希望時間帯が不明な場合
各日に複数の時間枠を提示する:
```
・3月2日（月）15:00〜 / 16:00〜 / 17:00〜
```

#### パターンB: 相手の希望時間帯が明確な場合
ピンポイントで提示する:
```
・3月2日（月）17:00〜18:00
```

### Step 5: 出力
1. まずユーザーに候補一覧をテキストで提示する
2. 承認されたらメール文面を生成する（コピペ用テキスト）
3. 必要に応じてGmailの下書きも作成する

## メール文面テンプレート

```
{相手会社名}
{相手名}様

お世話になっております。
株式会社Walkersの古谷でございます。

{前文（状況に応じて変更）}

下記の日程にて対応可能でございますので、ご都合の良い日時をお知らせいただけますでしょうか。

{候補日一覧}

※いずれも{所要時間}程度を想定しております。
上記以外でも調整可能ですので、お気軽にお申し付けください。

何卒よろしくお願いいたします。

───────────────────
株式会社Walkers
古谷 大輝
───────────────────
```

## 絶対守るルール
- **両方のカレンダーを必ずチェックする**（仕事 + 個人）
- **空き枠は1つずつ既存予定と突き合わせてバリデーションする**
- バリデーションなしで候補を出すことは絶対にしない
- ユーザーに確認する前に送信しない
