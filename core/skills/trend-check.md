# トレンド調査

トリガー: 「トレンド調べて」

## 実行手順

1. ユーザーからテーマ・業界・キーワードをヒアリングする
2. **Web検索** で最新トレンド情報を収集する
3. **X (Twitter)** でSNS上のトレンド・話題を収集する
4. 収集した情報を整理・分析する
5. レポートを生成して保存する

## 出力フォーマット

`output/trends/YYYY-MM-DD_[テーマ].md` に保存：

```markdown
# トレンドレポート: [テーマ]
生成日: YYYY-MM-DD

## サマリー
[3行以内の要約]

## 主要トレンド
1. [トレンド1]: [説明]
2. [トレンド2]: [説明]
3. [トレンド3]: [説明]

## SNSの反応
- [注目の投稿・意見]

## Walkersへの示唆
- [事業への影響・活用可能性]

## 情報ソース
- [URL/出典]
```

## ルール
- 情報ソースを必ず明記する
- 事実と推測を区別する
- Walkersの事業に関連する示唆を必ず含める
