# 【福岡県環境部様】「みんなの環境」デジタル版のご提案

福岡県環境部 環境政策課　永田 浩章 様 ／ 株式会社Walkers ／ 2026年5月28日

---

## 1. 提案概要

**本提案の目的**
毎年小学校に配布されている環境教育副読本『みんなの環境』を、ギガスクール端末でそのまま活用できるデジタル教材に再構築します。検索・動画・インタラクティブ要素を備えた副読本を主軸に、VR自然学習・環境クエスト・スタンプラリーをゲーミフィケーション補助教材として組み合わせ、児童の継続学習と県内自然への関心向上を支援します。

- **ターゲット：** 福岡県内の小学校児童（ギガスクール端末で利用） / 学校現場の先生
- **特徴：** ① 紙副読本のデジタル化を主軸に、ゲーム要素は副次的に組み合わせる ② すでに動くプロトタイプ（モック）で4機能を検証済み ③ 1年目MVP → 3年目本格導入の段階的アプローチで投資リスクを抑制
- **段階導入：** 1年目MVP（試作品 → 学校現場テスト運用） / 2年目フィードバック反映 / 3年目本格予算投入

## 2. 現状整理

**紙副読本の限界**
現在配布されている『みんなの環境』は全56ページ・4章構成で環境教育の基礎を体系的にカバーしていますが、紙媒体ゆえに用語検索や横断参照が難しく、動画など多メディア表現も組み込めません。授業時間外の自主学習にも結びつきにくい構造です。

**ギガスクール端末の活用余地**
県内の小学校では1人1台の端末が整備されている一方、環境教育領域でその端末を活用するコンテンツは限定的です。既存の紙副読本をデジタル教材として再構築すれば、配布コストを抑えつつ表現の幅を広げられます。

**自然体験機会の制約**
県内には学習に適した自然公園・在来種・外来種など豊かな題材がありますが、地理的・時間的制約から児童が直接訪れて学ぶ機会は限られます。VR・写真ベースの教材で「教室から県内自然を体験する」導線が求められます。

**継続学習の動機付け不足**
副読本だけでは「読み終わったら終わり」になりがちです。ゲーム要素や実地学習との接続によって、児童が自ら繰り返し学ぶ動機を生む仕組みが必要です。

| # | 現状の課題 | 本提案での解決方針 |
|---|---|---|
| 1 | 紙副読本の検索性・多メディア性不足 | 検索バー・動画埋込・用語ポップアップを備えたデジタル副読本 |
| 2 | ギガスクール端末の活用余地 | ブラウザだけで動く構成（インストール不要） |
| 3 | 県内自然の体験機会の制約 | VR自然学習（360度パノラマ＋生き物クリック詳細） |
| 4 | 継続学習の動機不足 | 環境クエスト・スタンプラリーで反復学習を促進 |

## 3. 提案ソリューション

『みんなの環境』のデジタル版を、**副読本を主軸**にゲーミフィケーション機能を補助として組み合わせた4機能で構成します。すべて動くモックを2026年5月時点で完成済みで、ブラウザ上での動作・操作感をすでに確認できます。

### 3-1. 主要機能一覧

| # | 機能 | 概要 |
|---|---|---|
| 1 | **デジタル副読本（主軸）** | 紙副読本（全56ページ・4章）をデジタル化。検索バー・動画埋込・用語ポップアップ・関連ページ参照・キャラクター吹き出し（かん太・きょう子・エコトンファミリー）で、児童が自ら触って学べる構成 |
| 2 | **VR 自然学習** | 県内自然公園で撮影した360度パノラマ写真をドラッグで見回し、映り込んだ生き物をクリックすると詳細情報を表示。在来種／外来種／景観の分類を学習 |
| 3 | **環境クエスト** | タブレットで環境課題に対するクイズに挑戦。正解を積み重ねるとアバターが成長し、ランキングで他校・他クラスと比較可能 |
| 4 | **スタンプラリー** | 野外学習会向け。指定された場所を訪れて生き物・現象を撮影するとポイント獲得、外来種発見でボーナス。図鑑として記録が蓄積 |

### 3-2. 副次的な拡張提案

- **AI 生物同定**：撮影した生き物をAIで自動同定する機能は技術的に実装可能ですが、誤判定リスクがあるため、5/20 MTGでの合意通り「先生による確認運用」を前提とします。1年目MVPでは見送り、フィードバックを踏まえて2年目以降に検討します。
- **マインクラフト連携**：街づくりを通じた持続可能性学習との連携は、副次的提案として将来的な拡張オプションに位置付けます。1年目MVPの範囲外とします。

## 4. 利用フロー

**児童の標準的な使い方**

1. ギガスクール端末でブラウザを開き、『みんなの環境 デジタル版』にアクセス
2. 副読本目次から学びたい章を選び、見開きを閲覧（検索・用語ポップアップ・動画も利用可）
3. 興味があれば VR自然学習で県内自然を体験、または環境クエストで学習を強化
4. 校外学習や自然学習会の際にはスタンプラリーで実地撮影
5. 学習履歴は端末に蓄積され、必要に応じて先生が確認

**先生の使い方**

- 授業の導入で副読本のサンプル見開きをプロジェクター投影
- スタンプラリーの撮影結果・AI同定候補を授業内で確認・修正
- クラスごとのクエスト進捗・ランキングをモニタリング

## 5. システム構成

| レイヤ | 技術 / 採用方針 |
|---|---|
| フロントエンド | Next.js 16（App Router）+ React 19 + TypeScript 5 + Tailwind CSS v4 |
| 配信 | Vercel（学校ネットワークから直接アクセス可能なクラウド配信） |
| 利用端末 | ギガスクール端末（ブラウザ完結／インストール不要／レスポンシブ対応） |
| 児童向け配慮 | 全文ふりがなユーティリティ（漢字へのルビ自動付与）／章別カラー設計 |
| データ | 副読本本文・用語辞典・VRシーン・クエストデッキはコンテンツ管理可能な構成 |
| 認証 | 1年目MVPでは未ログイン運用を想定（学習履歴は端末ローカル保存）。本格導入時に学校アカウント連携を検討 |

副読本本文・用語・VR写真などのコンテンツ更新は、要件定義フェーズで運用主体（県／学校／Walkers）を整理し、必要に応じて簡易な管理画面を1年目MVPまたは2年目で構築します。
