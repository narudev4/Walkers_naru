## 5. アプリケーション要件（問い合わせ原文ベース）

> 詳細な設計・構成・AI プロバイダーは **NDA 締結後に開示**される。以下は問い合わせ段階で開示された粒度。

### 5-1. システム種別・規模
- システム種別: **スマートフォン向け Web アプリケーション（iOS / Android 両対応）**
- 開発規模: MVP からスタートし、段階的に機能を拡張する**アジャイル型開発**

### 5-2. 想定ユーザー
- 日本在住の成人で、**家族・ペットとの日常を大切に思い、記録し管理したい**と思う方

### 5-3. アプリ概要
- 日常生活における**各種データを記録・蓄積**するスマホ向け Web アプリ
- 蓄積データをもとにした**ユーザーへのフィードバック機能**を備え、**継続的な利用を促す**

### 5-4. 主な機能区分

| 機能区分 | 内容（概要） |
|---|---|
| ユーザー管理 | 会員登録・ログイン・アカウント管理 |
| データ記録・閲覧 | 複数カテゴリのデータ入力・蓄積・履歴閲覧 |
| フィードバック機能 | 蓄積データをもとにした情報の提示・通知 |

### 5-5. 検討中の技術スタック・開発環境（先方提示）

| 区分 | 内容 |
|---|---|
| フロントエンド | Next.js / TypeScript / Tailwind CSS / shadcn/ui |
| バックエンド・DB | Supabase（PostgreSQL・認証・ストレージ） |
| ホスティング | Vercel（東京リージョン） |
| AI 連携 | 外部 AI API（HTTP 呼び出し） ※プロバイダーは NDA 締結後に開示 |
| 決済 | Stripe ／ GMO ペイメントゲートウェイ等を検討 |
| 開発ツール | v0 → Lovable → Cursor / Claude Code（3 段階アプローチ） |
