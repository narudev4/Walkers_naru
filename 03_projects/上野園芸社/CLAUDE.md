## サービス構成（2026-08-19 定例で確定）

- `kaketoco.com` ＝ 自作システム（Next.js / Vercel）。農薬検索・防除計画・マイ畑・AI QA
- `shop.kaketoco.com` ＝ Shopify。決済と商品・在庫管理を担うバックエンド
- **リバースプロキシによるサブディレクトリ統合は両方向とも見送り**。現状のサブドメイン分離を維持し、**Shopify 側を noindex にして SEO 評価を kaketoco.com に集約する**
  - ① Shopify を自社システム配下へ → 決済画面を Shopify ドメインから出せないため技術的に不可能
  - ② 自作システムを Shopify 配下へ → Cloudflare プロキシを Shopify が公式に非サポートと明言
  - ※ 定例では②の理由のみが説明された。根拠の全体は `research/2026-08-05_ドメイン構成調査.md`
- ブログ: 執筆は Shopify、表示は Shopify Blog API 経由で `kaketoco.com/blog`
- LP とトップページは分離。LP は開発チームが作成
