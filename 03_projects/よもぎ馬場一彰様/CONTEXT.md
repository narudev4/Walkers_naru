## 要件

### 元問い合わせ（2026-05-23）で提示された構成

- **予約/決済**: Square
- **自動化ハブ**: Make（旧 Integromat）
- **スマートロック**: RemoteLOCK（API利用）
- **通知**: LINE Messaging API

実装したい主な内容（6項目）:
1. Square 予約・決済 Webhook 連携（Webhook受信・決済状態判定・会員タグ判定）
2. 予約制限ロジック（未来予約件数制限・同一日予約制限・会員種別制御＝通常1件/プレミアム2件）
3. 部屋自動割り当て（00分開始→1号室、30分開始→2号室）
4. RemoteLOCK API 連携（PIN自動生成・利用時間のみ有効化・キャンセル時即時削除・変更時旧鍵削除＋再発行）
5. LINE通知（予約確定時に日時・部屋番号・PIN・利用案内を自動送信）
6. サブスク管理（Squareサブスク更新失敗時に会員タグ削除・未来予約キャンセル・鍵削除・LINE通知）

### 初回MTG（2026-06-01）での方針・更新

- **開発方式**: Make → **コードによる独自開発**（拡張性・ランニングコスト・AI開発効率）
- **予約機能**: 独自開発（既存ツールでは駐車場予約・会員ランク別制御が困難なため）
- **スマートロック**: RemoteLock 導入で合意
- **決済**: **Stripe で確定**（2026-06-04 ・ 対面販売がないため）
- **通知**: LINE（送信数課金に注意）
- **補助金**: **活用しない** — 新規事業＋法人登記前で補助金の要件を満たさないため
- **予算**: **200〜300万円台**、まずはミニマム構成で壊れにくい安定重視
- **新規要件**: 駐車場の事前予約機能（4部屋に対し駐車場2台分）／プレミアム・サブスクで予約開始時期を変える優先順位設定
