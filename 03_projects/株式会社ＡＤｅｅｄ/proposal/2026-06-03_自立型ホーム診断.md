# 【株式会社ＡＤｅｅｄ様】自立型ホーム診断のご提案

> 自立型老人ホーム（元気なうちに入居する施設）に特化した診断型集客サービス。大手ポータルが取りこぼす"自立層"を狙う。集客手段は未確定（要件定義で設計）。

## 表紙
- サービス名: 自立型ホーム診断
- 一行概要: Webで集客し、診断で条件に合う自立型老人ホームを3〜5件ご提案、一括資料請求につなぐ住み替え支援サービス
- 宛先: 株式会社ＡＤｅｅｄ　矢古宇 智士 様 ／ 株式会社Walkers ／ 2026年6月3日

## 1. 提案概要
- 目的: 老人ホーム広告事業の集客をオンライン化し、**元気なうちの住み替え**を検討するご本人・ご家族がWeb上で**自立型老人ホーム**を比較・資料請求できる仕組みを構築。LP＋診断ツールを小さく早く立ち上げ、将来は自立型特化ポータルへ発展させる二段構え。
- ターゲット: 元気なうちに住み替えを検討する自立シニアご本人と、情報収集を行うご子息・ご家族（自立した、元気なうちの入居検討層）
- 特徴: ①**AI・ノーコード駆動開発**で低コスト・短納期に構築／②診断→3〜5施設提示→一括資料請求のワンストップ動線／③**自立型特化で大手ポータルと差別化**・将来の特化ポータルへの段階設計
- ローンチ目標: 要件確定後、約2〜3ヶ月での公開を想定（テストマーケティング前提）
- 期待効果: 紙広告に依存しない、自立型施設のオンライン資料請求リード獲得チャネルを新設

## 2. 現状整理（自立型を主軸）
貴社は老人ホーム広告を主力に、施設との強固なネットワークと業界知見を強みとされています。特に**元気なうちに入居する自立型施設は、大手ポータルで要支援・要介護向け施設に埋もれ**、オンライン集客が難しいのが現状です。住まい探しがオンラインへ移行する今、自立型に特化したWeb集客の受け皿を整えることが次の成長機会になると考えます。

| 課題 | 詳細・現状 |
|---|---|
| 自立型施設のオンライン集客チャネルが無い | 紙広告中心で、元気なうちの住み替えを探すご家族がWeb検索で貴社に到達する導線がない。 |
| 大手ポータルで自立型が埋もれる | 「自立」で検索しても要支援・要介護も受け入れる施設ばかり表示され、自立専門施設が見つけられない。 |
| 住み替え検討層が比較しづらい | 自立型施設の費用・条件・立地が複雑で、ご家族が横断比較し資料請求するのに手間がかかる。 |

## 3. 提案ソリューション
**支援内容**: 自立型ホーム診断

「中古車の一括査定」「引越し侍」の**自立型老人ホーム版**にあたる診断型の集客サービス。Web経由で流入したユーザーが、希望エリア・予算・現在のご状態（自立度）・暮らしの希望などのアンケート→DBの条件分岐で条件に合う**自立型施設を3〜5件提示**→資料請求チェック初期ON→一括資料請求。広域エリアは町名を任意入力させ精度向上。**AI・ノーコードを活用した開発手法**で低コスト・短納期に構築。信頼補強としてメディア（記事）機能の追加も選択可能（拡張プランB）。
【将来展望】将来は**自立型特化ポータル／メディア**へ発展させ、SEO・LLMO で大手ポータルが取りこぼす自立層の集客を狙う。

| 機能 | 概要 |
|---|---|
| 集客LP | Web流入の受け皿。自立型施設への住み替え価値を訴求→診断へ誘導。 |
| アンケート診断 | 希望エリア・予算・現在のご状態（自立度）・暮らしの希望などを入力。 |
| 自立型施設マッチング（DB条件分岐） | エリア・価格帯・条件でDBから自立型施設を抽出し3〜5件提示。町名で精度向上。 |
| 一括資料請求 | チェック初期ON→一括請求フォーム。 |
| メディア／記事機能（拡張B・任意） | 自立型の住み替え記事をCMSで発信し、SEO自然流入・信頼補強。 |

## 4. ご利用フロー
オンライン流入（広告・検索・SNS等／手段は要件定義で設計） → 診断回答 → 自立型施設3〜5件提示（チェック初期ON） → 一括資料請求 → 送客・フォロー（貴社・各施設へ連携）

## 5. システム構成（技術具体化・モック実装準拠）
- フロントエンド: Next.js（React）。SSR/SSGでSEOと表示速度を両立（モックと同一構成）
- バックエンド: Vercel Functions（サーバーレス）で自立型施設マッチングロジック。AI・ノーコード駆動開発で工数圧縮
- データベース: Supabase（PostgreSQL）等のマネージドDBで自立型施設情報を管理・条件抽出最適化
- 計測・連携: GA4等のアクセス解析・コンバージョン計測、問い合わせ管理ツール連携
- インフラ: Vercel（モックと同一基盤）でスモールスタート→自動スケール
- AI活用: 開発フェーズでAIコーディング・ノーコードを活用し工数とコストを圧縮
- セキュリティ: SSL/TLS／個人情報のアクセス制御・最小権限／定期バックアップ・脆弱性対応
