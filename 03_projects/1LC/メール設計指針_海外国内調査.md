# 1LC マッチングメール 最適設計指針（海外・国内事例調査ベース）

> 作成: 2026-06-15 / naru
> 元データ: 海外（Zillow/Redfin/Realtor/Rightmove/Compass/Roofstock/Arrived/Stessa）＋ 国内（楽待・健美家・981.jp・通販大家さん）＋ HTMLメールUX（Litmus/Campaign Monitor/Email on Acid/Really Good Emails）の3方向調査

---

## 結論：naru 案「画像あり1件＋画像なし2件」は王道だった

3つの調査すべてが同じ構成を支持：
- **海外**：新着アラートは **2〜3件の少数キュレーション**が主流（Arrived「2 New Properties」/ Zillow「3 applause-worthy homes」が実例）。([Really Good Emails](https://reallygoodemails.com/categories/real-estate))
- **UX**：カタログ型は **3〜6点が上限**、構成は **ヒーロー1点＋サブ複数**が王道。3点はその下限の適正値。([Hustler Marketing](https://www.hustlermarketing.com/email-design-best-practices-for-ecommerce-in-2026-with-examples/))
- **CTR**：1メール＝1目的・1プライマリCTAで CTR が 3〜4% に乗る。単一CTAは複数CTAより **+371% クリック**。([Campaign Monitor](https://www.campaignmonitor.com/resources/knowledge-base/do-ctas-help-to-improve-email-response-rates/)、[Inman](https://www.inman.com/2025/12/12/why-your-real-estate-email-campaigns-arent-converting-yet/))

→ **画像が取れる物件（約4割）をヒーローに据え、画像なし物件2件をサブに置く**——画像のムラを構成でカバーする naru の発想は、事実ベースで最適に近い。

---

## 1. 全体構成（1通の骨格）

```
┌─────────────────────────────┐
│ ヘッダ（1LCロゴ／配信名）             │
│ パーソナライズ見出し                  │
│   「○○様の条件（エリア/利回り◯%以上/価格帯）に一致」│
├─────────────────────────────┤
│ ★ヒーロー物件（画像あり）              │ ← 主役。大きい写真＋利回り特大
│   写真 → バッジ → 価格 → 利回り → 立地 → 構造 → CTA│
├─────────────────────────────┤
│ サブ物件①（画像なし＝数字主導カード）       │ ← 色面＋特大利回り
│ サブ物件②（画像なし＝数字主導カード）       │
├─────────────────────────────┤
│ 末尾CTA（「条件に合う物件をもっと見る」）     │
│ フッタ（会社情報／配信停止／条件変更）        │
└─────────────────────────────┘
```

- **ヒーローのCTAを視覚的に支配的なプライマリ**に。サブにも各1ボタンを置いてよいが同格にしない。([Hustler Marketing](https://www.hustlermarketing.com/email-design-best-practices-for-ecommerce-in-2026-with-examples/))

---

## 2. 物件カードの中身（順序）

業界共通の縦順（投資家向けは利回りを追加）：

**写真 →（バッジ：新着/条件マッチ）→ 価格 → 利回り（表面＋想定を併記）→ 立地・最寄駅徒歩 → 築年・構造 → CTA**

- **利回り/ROI を価格と同格で前面**に。Roofstock/Stessa は cap rate・gross yield・想定賃料で表示、Arrived は配当利回りを判断軸に。([Stessa](https://www.stessa.com/investment-property-marketplace/)、[Roofstock](https://www.roofstock.com/investment-property-marketplace))
- 国内も同じ：楽待・健美家は **表面利回り＋想定利回り**を数値ファースト。([GALA NAVI](https://www.gala-navi.com/column/investment/c002342)、[不動産投資の森](https://2do-3.com/667/))
- **構造（RC/鉄骨/木造）と築年は必須**（融資年数に直結＝本気層が必ず見る）。
- 「想定（満室）利回り」であることを明記。曖昧な利回り表記は本気層ほど不信に。([アットホーム](https://www.athome.co.jp/contents/for-owners/toushi-kiso/rate-of-return/))

---

## 3. 画像なし物件の見せ方（配信の約6割を救済）★最重要

**空白・壊れ画像は厳禁。「画像欠落＝情報欠落」に見せない。** 業界標準の救済手法：

1. **特大の利回りライブテキストを画像の代わりの主役に**（数字でビジュアルを作る）。([Litmus typography](https://www.litmus.com/blog/email-typography-fonts))
2. **ブランド色の単色背景（色面）**を敷く＝画像ブロック/欠落でも崩れず質感を保つ。([Email on Acid](https://www.emailonacid.com/blog/article/email-development/html-background-images-in-email/))
3. **物件種別アイコン・地図・間取り**で視覚要素を補う。
4. やむを得ない場合は **listing placeholder（既定画像）**で一貫性を保つ。([Favethemes](https://favethemes.zendesk.com/hc/en-us/articles/39842788311316-Listing-Placeholder))

→ 数億円規模の投資家が対象なので、画像なしカードは **利回り・価格・立地・物件種別を大きな数字とアイコンで「数字で勝たせる」**。

## 4. 件名・パーソナライズ

- **件名**：`【新着】` or `【非公開】` ＋ 数値（利回り/エリア）＋ 条件マッチ感。50字以内。([LIFT 9訴求軸](https://www.gon-dola.com/lift/mailmagazine/4884/)、[ブラストメール](https://blastmail.jp/blog/mailmagazine/re-magajine))
  - 例：「【条件マッチ】武蔵関 徒歩7分・利回り6.93%の一棟RC」
- **本気層には「非公開・限定」が強い**（健美家の非公開・属性絞り込み配信と同じ心理＝自分だけ／早い者勝ち）。([健美家](https://www.kenbiya.com/info/service.html))
- **パーソナライズは氏名止まりにしない**。「エリア/利回り◯%以上/価格帯」まで動的化。saved-search 駆動の時系列アラートが最も成果が高い。([Luxury Presence](https://www.luxurypresence.com/blogs/real-estate-email-marketing/)、[Redfin Recommended For You](https://support.redfin.com/hc/en-us/articles/360001432712-Recommended-For-You))

---

## 5. CTA 設計

- **1メール＝1プライマリCTA**を支配的に。各カードに1ボタンは可だが視覚的優先度をつける。([Campaign Monitor](https://www.campaignmonitor.com/resources/knowledge-base/do-ctas-help-to-improve-email-response-rates/))
- **文言は動詞＋対象で具体的に**：「物件の詳細・収支シミュレーションを見る」「内見を予約する」。曖昧な「詳しく」は禁止。([Luxury Presence](https://www.luxurypresence.com/blogs/real-estate-email-marketing/))
- **実装はライブテキスト＋padding 方式（画像ボタン禁止）**、高さ 44〜72px、タップ領域 44px、コントラスト比 4.5:1。([Litmus bulletproof buttons](https://www.litmus.com/blog/a-guide-to-bulletproof-buttons-in-email-design))
- 国内慣行どおり **詳細ページ＋問い合わせ/電話の二段**も有効（良物件は早い者勝ち）。([通販大家さん](https://www.28083.jp/mm/))

## 6. 技術要件（メール互換・現行モックの作り直し必須点）

- **table ＋ インライン CSS**（flex/grid/外部`<link>`フォントは Gmail/Outlook で崩れる）。([Sonnet](https://sonnet.digital/the-edge/mastering-bulletproof-email-templates-tips-every-agency-should-know/))
- 幅 **600〜640px**、シングルカラム縦積み、横並びは2列まで（モバイルで縦化）。
- **利回り等の数字はライブテキスト**（画像化しない）。ダークモード約40%・画像ブロックでも消えない。([Litmus dark mode](https://www.litmus.com/blog/coding-emails-for-dark-mode))
- **ダークモード対応**：`<head>` に `color-scheme` meta、純白/純黒回避（#FDFDFD/#010101）、画像にスタイル付き alt。([Litmus](https://www.litmus.com/blog/coding-emails-for-dark-mode)、[Email on Acid alt text](https://www.emailonacid.com/blog/article/email-development/mastering-alt-text-in-email/))
- 画像は **1200px(2x) で用意し 600px 表示**、個別 200KB 以下・総量 800KB 以下。([Mailsoftly](https://mailsoftly.com/blog/email-design-best-practices/))
- **デスクトップ8割は好機**：デスクトップは click-to-open がモバイルの約2倍（≈21% vs ≈11%）。情報密度を上げられる。([Propphy 2026](https://www.propphy.com/blog/real-estate-email-marketing-metrics-2025-benchmarks-kpis))

## 7. 現行モック（`1lc_email_ideal.html`）からの改善点

| | 項目 | 評価 / アクション |
|---|---|---|
| ✅ | ヒーロー物件カード・利回り特大・単一CTA・条件マッチ明示 | **既に王道と一致。維持** |
| 🔧 | **サブ物件2件（画像なしカード）を追加** | 「1＋2」構成にして本調査の最適形へ |
| 🔧 | 画像なしカードのデザイン | 色面＋特大利回りライブテキスト＋種別アイコンで「数字で勝たせる」 |
| 🔧 | flex/外部フォント/クラスCSS | table＋インラインCSS に作り直し（メール互換） |
| 🔧 | 利回りの数字 | ライブテキストのまま（画像化しない） |
| 🔧 | ダークモード | color-scheme meta・純白純黒回避・styled alt |
| 🔧 | 会社情報 | `info@1core.com`→`info@1lc.com`、住所を実情報に |
