# AWS移行ロードマップ（岩下様GO取り用）

2026-08-03 作成。方針: **Airtable 上での改善はもう行わない。** 配信を AWS へ移す。

理由: Airtable Automation は 180秒・fetch45回の枠内に全処理を押し込む設計で、
物件が増える限り必ず遅くなる。実際 182回連続で "Failed to run"。
手元の Python で同じマッチングを実行すると 322人分が **0.10秒**（`40_AWSで作るもの一覧.md`）。
制約は Airtable 固有のものなので、直すより移す方が安い。

---

## Phase 1 — 配信を AWS に移す（本体）

**ゴール: 毎朝9時に紹介許可ON全員へ確実に届く。**

現行は「9時に起動して1人ずつマッチング→送信」なので遅い人は深夜になる。
移行後は **深夜4時に全員分のマッチングを済ませ、9時は送信だけ**にする。

| # | やること | 備考 |
|---|---|---|
| 1-1 | **バッチ実行基盤を作る** | **今の CloudFormation には無い。** Amplify + DynamoDB 4テーブルしか作っていない。EventBridge + Lambda（or ECS Scheduled Task）を追加する |
| 1-2 | マッチングを AWS 実装に移植 | 7条件 + 掲載終了除外 + 新しい順。**件数は3件**（メール表示数と揃える） |
| 1-3 | 紹介履歴を DynamoDB に持つ | 重複排除の原資。現行は Airtable で90日削除＝90日超の再紹介を防げていない。**照合キーを「メール埋め込み文字列」から 物件ID×投資家ID に変える** |
| 1-4 | Postmark 送信を AWS から実行 | テンプレ `lc-v3-prod`(45535824) はそのまま使える。トークンを **Secrets Manager** へ（現在スクリプトに平文） |
| 1-5 | **掲載終了チェックの日次化** | 現在は手動1回のみ。1日1.5%が掲載終了化。基盤ができれば安い |
| 1-6 | 失敗通知 | 実行失敗・新規0件24時間・送信失敗をメール/Chatwork へ。今は失敗しても誰も気づかない（182回の原因） |
| 1-7 | 築年数の不等号を確定 | 数値指定時の向き。岩下様確認待ちの唯一の仕様事項 |
| 1-8 | 切替（並行稼働→本番切替） | Airtable 側 Automation を OFF にする日を決める |

**Airtable に残すもの**: 物件データ・投資家マスタ・Interface（営業の操作面）。
Phase 1 では**読むだけ**にする。書き込みと判定を AWS 側へ寄せる。

## Phase 2 — ドメイン（Phase 1 と並行で着手）

**DNS 依頼は他社経由で往復が発生するため、Phase 1 の完了を待たず先に出す。**

| # | やること | 備考 |
|---|---|---|
| 2-1 | 岩下様経由で **PSI-Japan** にサブドメイン委任を依頼 | ドメイン/DNS は PSI-Japan、Webサーバーは DIX。**`1lcinc.com`**（`1lc.com` は1LC様のものではない） |
| 2-2 | Route 53 に NS 委任 → ACM 証明書 → Amplify カスタムドメイン | 「サブドメイン追加」を業者側で実行すると DIX のサーバーを指してしまう。必要なのは委任 |
| 2-3 | メール内リンクを新サイトへ差し替え | **ドメインが決まるまでは現行の土地大臣URLのまま**。`*.amplifyapp.com` は載せない（切替時にリンクとCookieが全部切れる） |

依頼の窓口は1回で確定させる。将来 SPF/DKIM/DMARC を足すときも同じ DNS を触る。

## 岩下様から取るべき GO（1回で）

1. **マッチングと送信を AWS へ移す**こと（Airtable 上での改善は行わない）
   - 根拠: 182回連続失敗／実際は紹介許可ON 322人の26〜56%にしか届いていなかった
   - 効果: 9時台に全員へ配信が完了する。物件が何万件に増えても変わらない
2. **配信件数を3件にする**こと（現在5件マッチして3件しか表示せず、残り2件が「紹介済み」として焼かれている。1日約156件）
3. **サブドメインの委任依頼**を PSI-Japan へ出していただくこと
4. **築年数の希望は「◯年以内」で確定**してよいか（新規登録フォームの保存値の確認）
5. 費用（月1万円以内の枠に収まる見込み）と、Airtable を当面併用すること
6. 切替日
