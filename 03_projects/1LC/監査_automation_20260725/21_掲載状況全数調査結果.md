# チタン物件一覧 掲載状況 全数調査結果

- 調査日時: 2026-07-25 19:25〜（読み取りのみ。Airtableへの書き込みなし）
- 方法: 全レコードの「公開用URL」をHTTP GETし、EUC-JPでデコードして
  `この物件は掲載を終了致しました` の有無で判定（同時接続8）
- 対象: 25,737件（URLを持つ全レコード。総レコード25,739件）

## 結果

| 判定 | 件数 | 割合 |
|---|---|---|
| ✅ 掲載中 | 11,958 | 46.5% |
| ❌ 掲載終了 | 13,779 | **53.5%** |
| ⚠️ 判定不能 | 0 | 0%（低速再判定で全件解決） |

**Airtableの物件データの過半数（53.5% / 13,779件）が、既にチタン側で掲載終了している。**
**判定不能はゼロ。全25,737件について掲載中/終了が確定した。**

## 意味

- マッチングは掲載中かを見ないため、母集団の半分が「死んだ物件」。今朝の実配信で
  掲載終了が43.1%混入していたのは構造的必然（別途 20_新旧比較.md 参照）
- 当初690件がHTTP 500で判定不能だったが、同時接続2・待機0.5秒の低速モードで再判定し全件解決
  （内訳: 掲載終了361件 / 掲載中329件）。原因は調査側の同時接続過多によるチタン側の一時エラー

- `sweep/sweep_result.json` … {レコードID: alive|ended|ended404|http500|error}
- `sweep/01_fetch_records.py` / `02_sweep.py` … 再実行可能なスクリプト（冪等・再開対応）
