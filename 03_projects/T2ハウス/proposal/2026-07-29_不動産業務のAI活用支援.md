## 1. 提案概要

**本提案の目的**

弊社では、御社の販売図面の作成と営業数値の集計を自動化するご提案をいたします。目的は2つです。作成と集計にかかっている時間を、AIとシステムで短くすること。そのうえで、出来上がった図面と数値に誤りが残らない状態をつくることです。進め方は初回MTGでお伝えした通りです。まず販売図面と営業数値の2つを、実データでの試運転の期間を確保して仕上げます。この2つが実運用に乗ったあとは、1〜2週間で1つの業務を自動化するペースで積み上げます。

**ターゲット：**

- 販売図面を作成される営業のご担当者
- 媒体別・担当者別の数値をご確認になる経営層の皆様

**特徴：**

- 販売図面の生成と検算をセットでご提供します。
- 営業数値の3つのファイルを1つに統合し、月をまたいだ比較を可能にします。
- 最初のサンプルは無料でご確認いただき、費用は要件定義を経てお見積もりをご提示します。

**ローンチ目標：** 販売図面の自動生成・自動検算の実運用化に着手し、実データでの試運転期間を含めて約1ヶ月での実運用開始を目指します。

## 2. 現状整理

**受領データの確認結果**

サンプル作成のため、NDA締結後にご提供いただいた販売図面のExcelと営業数値の3ファイルを拝見しました。いずれの業務も、サンプルの形まで自動化できることを確認しています。一方で、面積や坪数の計算、図面の複製、月ごと・ファイルごとの転記は現在すべて手作業のため、ここに時間がかかり、誤りにも気づきにくくなっていると考えています。拝見して確認した点は以下の4つです。

| 課題 | 詳細・現状 |
| --- | --- |
| 販売図面の数値に検算の仕組みがない | 面積の合計や坪換算が手計算のため、作成した値を元の数値と照合する手段がありません。弊社の検算では、坪換算や床面積の合計に小さなずれが複数見つかりました。 |
| 前の物件の記載や更新前の表記が次の図面に残る | 駅名の不一致や免許番号の版ずれなど、前の物件の記載や更新前の表記が残っている箇所がありました。図面を複製して次の物件を作成される際の、書き換え漏れと考えられます。 |
| 営業の数値が3つのファイルに分かれ、月をまたいだ比較ができない | 購入反響数・査定対応数・業者訪問一覧が別々のExcelで管理され、反響数と査定はさらに月ごとに別シートに分かれています。期中のご担当者の交代や表記の揺れもあり、月をまたいだ比較には手作業での組み替えが必要な状態です。 |
| 業者訪問の優先度がセルの塗り色で管理されている | 一覧表には「黄色は月に1度は必ず訪問する」と注記があり、対象はセルの塗り色で指定されています。最終訪問日からの経過を機械的に追う手段がないため、訪問の間隔が空いた先の拾い上げが、ご担当者の記憶と目視に頼る形になっています。 |

## 3. 提案ソリューション

**支援コンセプト**

**支援内容：販売図面の自動生成・自動検算と、営業数値の統合**

初回MTGで新島様より、ChatGPT等で見栄えの良い図面は作れるものの、細かなミスやエラーが解消しきれないとお伺いしました。謄本などからの情報の読み取りと文章の下書きはAIが担い、図面そのものはシステムのテンプレートが正確に組版します。面積や坪換算といった数値の整合性は、システムによる厳密な計算で検証し、この自動検算をクリアした正確なデータのみをPDF化する仕組みです。この検算機能は、自動生成時だけでなく、現行の手作業で作成されている図面の不備チェックにもそのままご活用いただけます。営業数値については、集計するだけでなく、ご担当者の交代や表記の揺れを吸収したうえで、比較できる形に整えます。

**主要機能一覧**

| 機能カテゴリ | 概要 |
| --- | --- |
| 販売図面の自動生成 | 住所・面積・構造・接道などの物件情報を入力すると、販売図面をPDFで出力します。謄本や物件調査メモからの読み取りにも対応します。レイアウトは現行の再現を基本に、デザインを改善した案もあわせてご用意しています。 |
| 販売図面の自動検算 | 出力の前に、面積の合計・坪換算・建ぺい率・容積率を計算し直して照合します。最寄駅と交通欄の不一致、宅建業免許番号の版ずれ、法令用語の誤字も検出し、該当箇所を一覧で表示します。 |
| 営業数値の統合 | 購入反響数・査定対応数・業者訪問一覧の3ファイルを、1つのデータに統合します。月ごとに分かれたシートと、期中に変わったご担当者の列を突き合わせ、月をまたいで比較できる形に揃えます。 |
| 媒体別・担当者別の集計 | 統合したデータから、媒体別の反響数、ご担当者別の成約率、査定から専任媒介までの推移を自動で集計します。数値の入力は現在の運用のまま、集計だけを自動化します。 |
| 業者訪問のフォロー管理 | 重点先の最終訪問日からの経過日数を自動で計算し、訪問の間隔が空いている先を一覧で表示します。セルの塗り色による管理を、日付にもとづく管理に置き換えます。 |

## 4. 導入の進め方

**1. モックアップのご確認：** 弊社にて、販売図面の生成と検算、営業数値の統合のサンプルを作成します。

**2. ご契約：** サンプルの内容にご満足いただけた場合に、要件定義へ進みます。仕様を確定したうえで、最初の2機能の開発費のお見積もりをご提示します。

**3. 業務のヒアリングと優先順位づけ：** 自動化する業務を弊社と御社で洗い出し、着手する順番を決めます。御社にお願いするのは業務フローのご説明のみで、エンジニアの方をご用意いただく必要はありません。

**4. 最初の2テーマを実運用に載せる：** 販売図面と営業数値の2テーマを、実物件のデータでの試運転と、入力ルールの確定に期間を確保して仕上げます。

**5. その後は1〜2週間で1つずつ広げる：** 2テーマが実運用に乗ったあとは、1つの業務につき1〜2週間で動くものを作り、対象を広げます。使ってみて出たご要望は、次の1〜2週間で反映します。初回MTGでは、ポータルサイトへの投稿、プロジェクト表の作成、メール・SMSの下書きなどが挙がっています。

## 5. システム構成

**開発形態**

**プラットフォーム：** ブラウザベースのWebアプリケーション

**対応デバイス：** PC・スマートフォン・タブレット（レスポンシブデザイン）

**推奨技術スタック**

**フロントエンド：** React（Next.js）を想定しています。

**バックエンド：** Pythonを想定しています。Excelの読み書き、PDFの生成、検算の処理を扱うライブラリが揃っているためです。

**データの保管：** 扱う件数と参照の仕方が決まった段階で選定します。最初の2つの自動化では、既存のExcelをそのまま入力として扱う想定です。

**インフラ：** クラウドの利用を想定しています。専用サーバーの購入や設置が不要で、利用量に応じた費用で運用できるためです。

上記は現時点の想定です。最初のタスクの要件が固まった段階で確定し、あらためてご報告します。

**セキュリティ対策**

- 通信はすべてHTTPSで暗号化します。物件情報・顧客情報を平文でやり取りしません。
- 利用はIDとパスワードによる認証制とし、御社の関係者以外はアクセスできない状態にします。
- 生成AIには、送信したデータを学習に使わない設定のAPIを利用します。個人情報は送信の対象から除外します。

## 6. 開発スケジュール

ご契約後の進め方です。まず要件定義を行い、サンプルでご提示した販売図面と営業数値の2機能を完成させます。その後は1〜2週間で1つの業務を自動化するペースで積み上げます。以下はご契約後3ヶ月間の想定です。

| フェーズ | 期間 | 主な作業内容 |
| --- | --- | --- |
| Phase 1 | 約2〜3週間 | 要件定義。業務フローのヒアリングを行い、販売図面と営業数値の2機能の仕様を確定させます。この期間で、初期開発費のお見積もりをご提示します。 |
| Phase 2 | 約3〜4週間 | 2機能の実装。販売図面の自動生成・自動検算から着手し、過去の物件で検算結果を突き合わせながら仕上げます。続けて営業数値の統合・集計と業者訪問のフォロー一覧を完成させます。 |
| Phase 3 | 約1〜2週間 / 1機能 | メール・SMSの下書き、プロジェクト表の作成など、軽めの業務から1〜2週間に1件のペースで自動化を広げます。ポータルサイトへの投稿は、要件を確認のうえ着手時期をご相談します。 |

## 7. 概算見積もり

費用は、最初の2機能の初期開発費と、その後の月額伴走費用の2本立てです。月額伴走の条件は、初回MTGでお伝えした通りです。想定する稼働時間が変わる場合は、あらためて月額をご提案します。

| 項目 | 概算金額 | 備考 |
| --- | --- | --- |
| 初期開発費（販売図面・営業数値の2機能） | 要件定義後にお見積もり | Phase 1 の要件定義で仕様を確定し、工数にもとづく本見積もりをご提示します。 |
| 月額伴走費用（想定稼働20時間/月） | 300,000円/月 | 2機能の実運用開始後の伴走費用です。時間単価15,000円×想定稼働20時間で算出し、軽めの業務を2週間に1件程度のペースで自動化します。 |
| 稼働時間を増やす場合 | 時間単価15,000円で加算 | ご要望に応じて稼働時間を増やす場合は、あらためて月額をご提案します。契約期間の縛りは設けません。 |
| 合計 | 初期開発費＋月額300,000円 | （税別）初期開発費は要件定義後に確定します。月額は想定稼働20時間の場合です。 |

月額伴走費用（固定）：300,000円。想定稼働20時間・時間単価15,000円で算出しています。
