## 1. 提案概要

7月2日のお打ち合わせでお伺いした課題をふまえ、貴社のフリーランスエンジニアマッチング業務を支援する基盤の構築をご提案します。案件情報の入力から候補エンジニアのご提案までをAIで支援し、あわせてプロフィール管理・案件管理・フリーランスの方との連絡を一元化します。

- ターゲット: 貴社の営業担当者・キャリアアドバイザー(社内向け業務システム)
- 特徴: ①案件概要入力だけで候補エンジニアを自動提案(マッチ率・紹介文つき) ②履歴書マスキング・面談記録のDB反映を自動化 ③分散した連絡チャネルの一元管理と対応漏れ検知
- ローンチ目標: 要件定義フェーズにて確定
- 期待効果: 候補選定・紹介文作成・連絡管理にかかる担当者の作業時間の削減

## 2. 現状整理

| 課題 | 詳細・現状 |
|---|---|
| 候補エンジニアの選定が人力 | 案件概要と登録エンジニアの突き合わせを担当者の記憶と手作業に頼っており、候補提案までに時間がかかる |
| プロフィール管理が手作業 | 履歴書マスキング、面談内容のDB入力を人手で実施 |
| 案件・連絡先の分散管理 | 案件は営業ごとにスプレッドシート等で個別管理。連絡はLINE・Chatwork等に分散し、面談日程の連絡漏れ・リマインド忘れが発生 |

## 3. 提案ソリューション

支援内容: AIマッチングを核とした業務基盤の構築支援(PMキャリア/PMクラブでのマッチングシステム開発実績あり)

| 機能 | 概要 |
|---|---|
| AIマッチング | 案件概要から候補5名程度をマッチ率つきでレコメンド。紹介文自動作成 |
| エンジニアプロフィール管理 | 履歴書マスキング自動化、面談議事録からのDB自動反映 |
| 案件管理 | 全営業の案件を一元管理。仕分け会議議事録からステータス自動更新 |
| 統合インボックス | LINE・Chatwork等を1画面に集約。未対応・要リマインドをAI検知 |
| ダッシュボード | 案件・人材・未対応連絡を1画面で確認 |

## 4. 支援方向性(2パターン)

1. **A. コンサル支援型(準委任契約)**: コンサル1〜2名が現場課題を伺いながら優先度順に実装・改善を継続
2. **B. 請負開発型**: 要件定義で仕様確定後、請負契約で開発。成果物と金額を事前固定
3. **共通**: 最初に要件定義を準委任で実施 → 完了後に本見積り提示

## 5. 開発スケジュール

| フェーズ | 期間 | 内容 |
|---|---|---|
| Phase 1 | 約1〜1.5ヶ月 | 要件定義(業務フロー整理・範囲確定・仕様策定)。完了後に本見積り |
| Phase 2 | 約2〜3ヶ月(要件定義後確定) | AIマッチング等の中核機能から段階的開発 |
| Phase 3 | 約2〜4週間 | 実データ検証・操作説明 |
| Phase 4 | 継続 | 運用サポート・効果測定と改善 |

## 6. デジタル化・AI導入補助金の活用

- 補助率: 1/2〜2/3(申請区分により変動)、補助上限は年度の公募要領による
- 対象費目(登録ITツール導入費・クラウド利用料・導入役務)は申請前に整理
- 交付決定後着手が原則: 要件定義(自費)→申請→交付決定後に開発着手
- 申請サポート: 成功報酬 採択額の8〜15%

## 7. 概算見積もり(税別)

| 項目 | 概算金額 | 備考 |
|---|---|---|
| 要件定義フェーズ(準委任) | 39〜90万円 | 13,000〜15,000円/h×30〜60h |
| 開発フェーズ(MVP) | 概算150〜300万円 | 要件定義後に本見積り提示 |
| 補助金申請サポート(任意) | 成功報酬: 採択額の8〜15% | ご希望の場合のみ |

ランニングコスト: 保守サポート(固定・要件定義後提示) / AI API利用料(変動・実費精算)
