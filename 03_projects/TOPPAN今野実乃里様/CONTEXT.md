## 1. プロジェクト概要

スーパーマーケットの既存会員アプリ（約 30 万人）向けに、**多業種クーポン配布 Web アプリ**を新規開発する。
地元企業（ガソリンスタンド等）がキャンペーンに参加し、各社で使えるクーポンをアプリ会員に配布する仕組み。
既存アプリとは別システムとして構築し、会員番号 API 連携でログイン認証を行う。

## 4. システム要件（初回 MTG 時点）

### ユーザー向け機能

| 機能 | 詳細 |
|---|---|
| ログイン | 既存アプリの会員番号で API 認証（セッション引き継ぎは初期不要） |
| クーポン一覧 | 配布中クーポンの閲覧（加盟店・条件・有効期限） |
| クーポン使用 | バーコード表示 / ボタン押下 / スタッフ手動値引き（方式は要検討） |
| 使用履歴 | クーポン使用履歴の閲覧 |

### 管理者向け機能

| 機能 | 詳細 |
|---|---|
| ダッシュボード | 期間指定でクーポン使用数等を確認 |
| クーポン管理 | 作成・編集・配布設定（回数制限、有効期限等） |
| 加盟店管理 | 参加企業の登録・管理 |
| データエクスポート | CSV 形式で提携企業にデータ提供 |
| AI サマリー | 使用状況の自動サマリー作成 |
| PDF 出力 | レポートの PDF 出力 |

### 加盟店向け機能（要検討）

| 機能 | 詳細 |
|---|---|
| 自社データ確認 | 自社クーポンの使用データを確認可能にする |
| 使用確認 | クーポンコード使用履歴を確認し重複使用を防止 |

### セキュリティ・不正対策

| 項目 | 方針 |
|---|---|
| スクショ対策 | 初期は不要。長期運用決定時にクーポンコード定期更新で対応 |
| 重複使用防止 | DB に使用履歴記録 + 現場スタッフ確認機能 |
| クーポンコード更新 | 30秒〜2ヶ月の周期で更新可能（要件確定後決定） |
