## 設計判断サマリー

詳細: [design-decisions.md](design-decisions.md)

| # | 判断 | 要点 |
|---|------|------|
| 1 | 成果物タイプ A（業務システム） | ヒーロー見出し・宣伝コピーなし、情報密度優先 |
| 2 | カラー: Emerald + Amber | スーパー・食品の信頼感 + クーポンのお得感（ブランド色未確認のため汎用色） |
| 3 | フォント: Zen Maru Gothic + BIZ UDPGothic | 幅広い年齢層（20〜70代）の可読性確保 |
| 4 | クーポン使用 3 方式全て実装 | MTG で「どれを採用するか」の議論材料として全パターン提示 |
| 5 | CSS のみの棒グラフ | Chart.js 不使用でモックアップの軽量性維持 |
| 6 | 4 桁コード入力 UI | IT リテラシーが様々な加盟店スタッフ向けにシンプル設計 |
