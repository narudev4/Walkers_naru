# 【合同会社どうぶつとひと出版様】獣医師向け 論文お知らせサブスクサイトのご提案

- サービス名（仮称）: 獣医師向け 論文お知らせサブスクサイト

## 1. 提案概要

獣医師が日々の診療のなかで最新の獣医療文献に触れる時間を確保しづらい——この課題に対し、本サービスは「AI による日本語要約（無料）」と「招聘した先生による解釈コメント付き記事（有料）」の二層構造で、忙しい獣医師が"先生の視点"とともに最新文献へ効率的にアクセスできる環境を提供します。

- **目的**: 解釈コメント付きの論文ダイジェストを週1回配信するサブスクリプションサービスの構築
- **ターゲット**: 臨床獣医師（専門領域・関心カテゴリ別）
- **中核価値**: 単なるAI翻訳ではなく「先生の解釈」が付くことに課金価値を置く
- **提供形態**: 会員登録 → サブスク購入 → 配信通知 → サイトで閲覧・マイBOX保存

---

## 2. 現状整理

- **一次文献（英語論文）へのアクセス障壁**: 最新の獣医療エビデンスは PubMed 等の英語論文が中心で、診療の合間に読み解く負担が大きい。
- **既存類似サービスとの差別化**: 参考サービス（medrock／ronbunapp、medilens-intelligence、carenet 等）は文献の翻訳・要約が中心。本サービスは「招聘した先生による解釈コメント」を核に据える点が差別化軸。
- **配信・運用を無理なく回す仕組み**: 著者からの原稿受領 → 配信 → 会員通知の流れを、運用負荷を抑えて回せる設計が必要。

## 4. ご利用の流れ

1. 会員登録
2. サブスク購入（Stripe 決済）
3. 週1回、☆コンテンツを配信し会員へ通知
4. サイトで記事を閲覧（無料＝要約／有料＝解釈コメント全文）
5. 気になる記事をマイBOXに保存（"後で読む"・カテゴライズ）

---

## 5. システム構成

### 開発形態
コードによるフルスクラッチ開発（Webアプリケーション）

### 主要技術要素（詳細は要件定義で確定）
- フロントエンド／バックエンド: モダンな Web フレームワーク（要件定義で選定）
- データベース: 記事・会員・マイBOX 等の管理
- 論文情報源: **PubMed API（NCBI E-utilities）** ※利用条件（無料枠・レート制限）は当社にて調査中
- AI翻訳・要約: 生成AI（OpenAI API 等）。獣医師向けに専門用語へ配慮した日本語要約
- 決済: Stripe
- 通知: LINE 連携（当初は手動運用、自動化は将来拡張）

### セキュリティ
- 決済は Stripe に委譲し、カード情報を自社で保持しない
- 通信暗号化（HTTPS）、認証・認可の適切な実装、会員情報の保護

## 7. 補助金活用戦略

本提案は、**AI導入補助金（デジタル化・AI導入補助金）の活用**を前提に設計しています。御社の当初ご予算（300万円程度）に補助金を組み合わせることで、ご負担を抑えながら、サービスの中核に加えて周辺領域（AI機能の高度化・既存事業のDX）まで一度に実現することを狙います。

- **補助対象の想定**: 上記見積もりの ①サイト本体・②AI高度化・③在庫管理DX を補助対象として申請する想定です（対象費目・申請枠は申請時に確定）。
- **補助率**: **1/2〜2/3**（申請区分・賃上げ要件等で変動）。
- **補助金額・実質負担**: 総額約600万円に対し、補助 **約300〜350万円** → **実質的なご負担 約250〜300万円**（いずれも当初ご予算の範囲内）。
- **資金繰りのご留意点**: 補助金は精算払い（後払い）のため、**一旦は総額をお支払いいただき、事業完了後に補助金が入金**されます。
- **スケジュール**: 「要件定義（自費）→ 補助金申請 → 交付決定後に開発着手」の順となります（交付決定前の発注・契約・支払いは補助対象外のため）。
- **当社の支援**: 申請のサポートを行います（成功報酬：採択額の8〜15%。代行は不可）。採択後は年1回の事業化報告（軽微）。

> ※補助対象費目・申請枠・補助率・補助上限・還付額は、御社の状況と申請区分により確定します。本記載は現時点の概算であり、確定値は申請区分の決定後にご提示します。
