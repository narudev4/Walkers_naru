## 4. 要件（先方の構想 ＋ 提供PDF）

### コア（☆コンテンツ＝有料の核）
- 著者（先生）が論文を翻訳＋解釈コメントを付けた記事を作成（例: A先生に月4本依頼、原稿料を払って執筆）。**週1配信**。
- 単なるAI翻訳ではなく「先生の解釈」が付く点に課金価値。

### 有料/無料
- **有料（月400円）**: 著者の解釈コメント全文、マイBOX（カテゴライズ／チェック／"後で読む"／ゴミ箱）、検索性
- **無料**: 論文タイトル＋サマリー、AI翻訳・AI要約部分

### +α（無料）
- 文献検索→日本語訳（＋要約）→マイBOX保存

### 将来拡張
- 興味カテゴリ登録→該当論文の定期自動配信（タイトル/要約のみ）
- 今週よく読まれた記事 TOP3 のお知らせ

### 配信/通知
- 会員登録→サブスク→**LINE通知→サイト遷移**。LINE自動連携は重い/高コストのため、当初は手動運用も許容、自動化は将来。

### 技術スタック（※方針未確定）
- **先方PDFの希望**: ノーコード（Airtable / Make / OpenAI API〔GPT-4o-mini〕/ Softr or Webflow + Memberstack / LINE Messaging API / Stripe決済）
- **当方の提案方針**: **コードで開発**（ランニングコスト安・自由度/品質高・結果的に早い）。→ 次回すり合わせの核心
- 論文情報源: **PubMed API**（無料利用可否を当方調査中）
- 参考サイト（PDF記載）: medrock.co.jp/ronbunapp ／ medilens-intelligence.com ／ pmc.carenet.com
