## デザイン方針
- [ ] カラーテーマ: Wi2 コーポレートカラー（青系 #0066CC ベース）を採用。理由: Wi-Fi / KDDI のブランドイメージと合致

## 画面設計の判断

### A-1 メインダッシュボード
- [ ] KPI カードは4列: 月次計上額 / 商談数 / 受注率 / 新規取引先数
- [ ] グラフ: 計上額推移（折れ線）+ 商談フェーズ分布（ドーナツ）+ 営業本部別計上額（横棒）
- [ ] 直近活動フィード: 最新5件表示

### B-1 商談一覧
- [ ] デフォルトソート: 更新日降順
- [ ] 表示列: 商談名 / 取引先 / フェーズ / 計上額 / 担当者 / 更新日
- [ ] フィルタ: フェーズ / 営業本部 / 担当者 / 期間（年月）

### B-2 商談パイプライン（カンバン）
- [ ] フェーズ: リード → 提案中 → 見積提出 → 交渉中 → 受注 / 失注
- [ ] カード表示: 商談名 + 取引先名 + 計上額

### B-3 商談詳細
- [ ] 収益構造を明示: 構築費（一括）と月額サブスク（ランニング）を分離表示
- [ ] 活動タイムラインを右カラムに配置
- [ ] 関連 AP/機器セクションを含める（Wi2 固有）

### B-4 商談作成・編集
- [ ] 取引先はインクリメンタルサーチで選択
- [ ] 金額入力: 構築費 / 月額 / 計上額の3フィールド

### C-2 取引先詳細
- [ ] タブ切替: 基本情報 / 商談 / 担当者 / 設置AP
- [ ] 業種バッジ表示（自治体 / 飲食チェーン / ドラッグストア 等）

### G-2 サイドバー
- [ ] メニュー構成: ダッシュボード / 商談 / 取引先 / 担当者 / AP管理 / レポート / 設定
- [ ] 折りたたみ対応
- [ ] ユーザーアバター + 営業本部名を表示
