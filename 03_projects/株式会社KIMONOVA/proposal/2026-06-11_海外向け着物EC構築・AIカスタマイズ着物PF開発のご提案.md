## 1. 提案概要
本提案は、海外向け着物事業を展開する貴社のシステム基盤を2本立てで構築するもの。
①既存の着物販売を Shopify で EC 化し、②海外富裕層が自分だけの着物をデザインできる AI カスタマイズ着物プラットフォームを開発。

- ターゲット: 海外富裕層（顧客向け画面は英語のみ、管理画面は日本語）
- 特徴: ①Shopify で海外向け EC を低コスト・短期立ち上げ ②パーツ選択式＋画像生成AIの着物デザイン体験 ③アプリDL不要・ブラウザ完結のWebアプリでストア手数料を回避
- ローンチ目標: Shopify は早期着手・短期構築。AIプラットフォームは補助金交付決定後（9/2以降）に本開発着手
- 期待効果: Instagram・紹介に依存しない海外販売チャネルの確立と、オーダーメイド着物の新規事業立ち上げ

## 2. 現状整理
着物の海外販売は現在 Instagram と紹介コミュニティ内のみ。本格稼働2〜3ヶ月・3名体制。EC基盤がなく海外向けの販売チャネル・決済が未整備で事業拡大のボトルネック。

| 課題 | 詳細・現状 |
|---|---|
| EC基盤の不在 | Instagram と紹介で完結し海外決済対応チャネルがない。新規顧客の獲得・拡大が困難 |
| 新規事業の基盤がゼロ | AIカスタマイズ着物はデザイン〜注文〜製造をつなぐシステムが未構築。織屋選定も属人的 |
| 創業期ゆえの投資制約 | 2〜3ヶ月・3名体制。初期投資を抑えつつ将来拡張に耐える構成と補助金活用が必要 |

## 3. 提案ソリューション
共創パートナーとして補助金申請・要件定義・開発・運用まで一気通貫で支援。海外顧客がパーツを選び AI 生成の柄を組み合わせてデザインできる PF を、パーツ選択式（複雑さを管理しつつ創造性を発揮）で構築。

| 機能カテゴリ | 概要 |
|---|---|
| パーツ選択デザイナー | 設定済みパーツ（型・配色・柄ブロック）を組合せ。前袖・後ろ袖などブロック単位で柄配置 |
| AI柄生成 | キーワード入力（例:鳥、ピンク）から画像生成AIが柄を自動生成。海外ニーズの自由度を確保 |
| デザインプレビュー | ブロック単位の柄配置を反映したプレビュー表示 |
| 注文・サイズ入力 | 発注の最終段階でサイズ入力、Shopifyで決済 |
| 連携・管理 | Shopify連携（受発注・決済・顧客管理）、日本語の管理画面 |

## 4. ご利用フロー（AIカスタマイズ着物）
1. パーツ選択: Webアプリにアクセスしパーツ選択
2. AI柄生成・プレビュー: キーワードから柄生成、プレビュー確認
3. サイズ入力・注文: 最終段階でサイズ入力、Shopifyで決済
4. 製造（織屋マッチング）: 柄に応じた織屋で製造（初期は人力運用、将来システム化）
5. 海外配送・お届け: 製造期間 半年〜1年。オーダーメイド体験を付加価値に

## 5. システム構成
- 開発形態: ブラウザベースのWebアプリ（PC・スマホ・タブレット対応／モバイルアプリ不要）
- 技術スタック: 具体構成は要件定義で確定。AI開発・ノーコードの知見で低コスト・短期構築。受発注・決済はShopifyに集約、PF側で決済情報を保持しない
- セキュリティ: 決済情報はShopify側で完結 / SSL/TLS・アクセス権限管理 / 顧客データの適切管理・定期バックアップ

## 6. 開発スケジュール
| フェーズ | 期間 | 主な作業内容 |
|---|---|---|
| Phase 1 | 約2〜3週間 | 要件定義・設計（準委任）：詳細要件（パーツ構成・柄生成方式・織屋連携）と補助金申請準備 |
| Phase 2 | 約1〜1.5ヶ月 | Shopify構築：ストア構築・英語化・海外決済設定・デザインカスタマイズ |
| Phase 3 | 申請〜交付決定 | 補助金を申請し交付決定を待機（申請可否のご判断は6月中を推奨） |
| Phase 4 | 交付決定後 | プラットフォーム本開発：Shopify連携・テスト・ローンチ |

## 7. 補助金活用戦略
- 活用予定: AI導入補助金
- 補助上限: 補助率 1/2〜2/3・申請区分により変動
- 活用イメージ: Shopify（受発注・決済）とAI着物PF（買い切り型ソフトウェア）を補助対象として申請。補助額は申請区分・要件により変動するため要件確定後に提示
- 戦略: ①費目構成の最適化（買い切りSWと導入支援を概ね1:1）②交付決定後着手の徹底 ③不採択時の安心設計（結果が出るまで請求保留、不採択時は実施分のみ請求）
