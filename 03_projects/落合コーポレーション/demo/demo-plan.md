## 4. ブランディング方針（先方指示なし・naru 解釈）

### 制約
- **コーポレートサイトはプロパゲート社にて別途制作中**（提案書 v3 明記）
- 公式 EC・コーポサイトはまだ公開されていない
- **参照可能なブランドアセットは現時点で存在しない**
- → デモでは「中立的・実直なメーカートーン」で組み、本番化は **プロパゲート社の成果物が出てから合わせる**

### 推定トーン（提案書から読み取り）
- 老舗バドミントンシャトル製造メーカー（B2B 卸売主軸 → B2C 拡張）
- 課題: アナログ受注・送り状手入力ミス → **「正確さ・信頼性」が刺さるキーワード**
- ターゲット:
  - B2C: バドミントン愛好家・コーチ・部活動・個人
  - B2B: スポーツ店・販売代理店・大口取引先
- 派手な D2C 系ではなく **スポーティ × 業務的 × 信頼感**
- 参考の同業: ヨネックス公式 / GOSEN / ラケットショップフジ / Mizuno
- B2B 卸 EC の機能性: モノタロウ / MISUMI

### 推奨パレット（提案・先方確認必要）
- **メイン**: ネイビー（信頼感・スポーツ・卸売の定番）
- **アクセント**: レッド（バドミントン日本代表カラー連想） or グリーン（コート連想）
- **ベース**: 白 / ライトグレー
- フォント: 標準和文（Noto Sans JP 等）
