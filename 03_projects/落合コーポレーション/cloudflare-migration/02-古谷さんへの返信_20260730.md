### 掛率のメタフィールド → **`b2b.*` ＋ `discount_matrix` が現役です**

| 系統 | コードからの参照 |
|---|---|
| `b2b.*` ＋ `discount_matrix` | **98 箇所** |
| `custom.*` ＋ `customerclass` ＋ `itemtype` | **0 箇所** |

上の Draft Order 検証がこの経路です（`b2b.discount_group=A` × `b2b.category=racket` → `discount_rate=0.6`）。

**決定的なのは、2 系統で数値の意味が逆だという点です。**

| | 意味 | 顧客区分 A の値 |
|---|---|---|
| `discount_matrix`（現役） | **掛率** | racket = `0.6` → 定価の 60% で買える（40% 引き） |
| `customerclass`（残骸） | **割引率** | typeA = `30` → 30% 引き（＝掛率 0.7 相当） |

**同じ「顧客区分 A」で 0.6 と 0.7、しかも数値の向きが逆です。** ご懸念どおり、9 月に実値を `customerclass` 側へ入れると価格が壊れます。

削除対象（コードからの参照が 0 なので消しても実装は壊れません）:

- 商品 `custom.itemType`
- 顧客 `custom.2_f` / `custom.itemAdiscountRate` / `custom.itemBdiscountRate` / `custom.itemCdiscountRate`
- メタオブジェクト `customerclass`（4 件）/ `itemtype`（3 件）
