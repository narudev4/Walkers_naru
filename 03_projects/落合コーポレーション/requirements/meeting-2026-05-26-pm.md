## 1. B2B 仕様（運用ルール）

### 登録方式
- **招待制** を採用
- **初期 ID/パスワード を Walkers 側で発行**
- ID は **メールアドレスではなく独自の顧客番号**
- セキュリティの観点で **初回ログイン後にパスワード変更必須**

### アクセス制限
- B2B サイトは **招待制**、**ゲスト購入不可**
- コーポサイト ↔ B2B サイト は **紐付け**
- **B2C と B2B は繋げない**（B2C → B2B 導線も作らない）
- コーポサイトからのログイン導線は **プロパゲート社と連携して対応**

### 掛け率管理（最重要・複雑）
- **2 軸** で柔軟管理:
  - **顧客側**: グループ単位（A ランク / B ランク...） + **個別顧客カスタム**
  - **商品側**: 商品区分（ラケット / ウェア / シューズ 等）別レート
- **顧客 × 商品区分** の組合せで掛け率を決定
- **単純固定レートではない**
- 営業担当者が顧客ごとに細かく対応できる柔軟性を確保
- **「新しい商品カテゴリが増えても再開発不要」な設計** が要件
- 古谷さんがデモンストレーションを作成して提示する

### 送料ルール
- **B2C**: 8,000 円基準
- **B2B**: 地域・取引額別
  - 2 万円 / 3 万円 / 沖縄 5 万円 等
  - 荷物単位で計算

### 在庫アラート
- 商品ごとに在庫管理状況が異なる
- **一律ではなく、商品ごとに設定**

### 商品カテゴリ分類
```
バドミントン / テニス / ピックルボール / パデル
  ├ ラケット
  ├ シューズ
  ├ ボール（シャトル）
  ├ ストリング   ※テニスからは削除
  ├ ウェア
  └ アクセサリー
```
- シャトル番号（1-5）等のバリエーション表示は **商品ごとに最適な見せ方を都度確認**

## 2. 決済戦略（最重要論点）

### B2B 決済
- **銀行振込が必須条件**
- マネーフォワードで会計業務・請求書発行を実施中
- **決済手数料を避けたい**、既存オペレーション維持

### Shopify 規約上の問題
- Shopify での請求書払い実装で「**決済を Shopify 外に逃す**」手法は手数料抑制できる
- しかし **Shopify の利用規約に抵触する恐れ**
- → 古谷さんが調査
- **代替案**: Shopify 外に **B2B 専用システム**構築、在庫だけ API 連携
  - 予算 50 万 / 補助金時 100 万
  - サーバー費・運営コスト増の懸念
  - 慎重に検討

### B2C 決済
- **クレジットカード + PayPay** 優先
- 実店舗端末（スクエア等）増やすと管理煩雑 → 増やさない
- Shopify 商品ページに **QR コード配置 → オンライン決済誘導**

## 3. データ統合

### Shopify ↔ マネフォ
- Shopify 売上を **手入力なしでマネフォに自動連携**
- 連携手法は技術調査含めて検討

### 既存商品データの統合
- 落合側に **JAN コード Excel** と **商品管理 Excel** が存在
- 2 つは **完全には紐付いていない**、整理必要
- 古谷さんから「**両 Excel を使わなくて済む状態にする**」提案
- 落合社合意 → サンプル共有依頼済み（赤字部分を要検討）

### 商品登録方法
- 手動 1 件登録 / Excel・CSV 一括インポート の 2 通り
- **画像はどちらでも個別作業必要**
