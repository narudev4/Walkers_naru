# マニュアル v3 修正仕様（naru レビュー 2026-08-19 未明・全 10 項目）

対象ファイル: `m1-sections.html`・`m2-sections.html`・`../33-操作マニュアル_v3見本_C3_20260818.html`（C-3 の 3 ページ部分のみ）。
**付録 A/B/C の 3 ページは修正禁止**（後で削除予定のため触らない。ただし壊さない）。

## 1. 章番号を数字に統一

- 1章 はじめに（旧 0 章）／2章 商品を売る準備（旧 A）／3章 業者様を迎える（旧 B）／4章 注文から発送まで（旧 C）／5章 請求と入金（旧 D）／6章 お知らせと問い合わせ（旧 E）。
- とびらページの章名・band タイトルの「A-1」「B-3」等の**節プレフィックスは全削除**（例:「B-3　割引率の表を編集する」→「割引率の表を編集する」）。STEP 丸数字は節内連番のまま。

## 2. 本文中の節参照はページ番号に

- 「（C 章）」「（B-3）」「（A-4）」等の参照は、**章参照→「（4章）」、節参照→「（P.◯◯）」**に変える。
- ページ番号は結合時に自動解決する。書き方: 各節の最初の `<section class="page"` に `id="sec-a1"` 形式の id を付け（a1,a2,a3,a4,b1,b2,b3,b4,c1,c2,c4,c5,d1,d2,d3,d4,d5,e1,e2。1章は sec-login/sec-map/sec-rules）、参照箇所は `P.<span class="pref" data-ref="sec-b3"></span>` と書く。結合スクリプトが実ページ番号を埋める。
- C-3 への参照は `data-ref="sec-c3"`（C-3 側の 3 ページの最初にも `id="sec-c3"` を付けること）。

## 3. 数字・英語の前後の半角スペースを削除

- テキストノード内の「日本語文字と半角英数字の間の半角スペース」を除去する（例:「3 つ」→「3つ」、「B 章」→「B章」、「Walkers に」→「Walkersに」、「約 3 分」→「約3分」）。
- **英数字同士の間のスペースは残す**（「STEP 1」「P. 」は対象外。ただし「P. 21」型があれば「P.21」に）。
- HTML の属性値・クラス名・URL・`<code>` 相当には触らない。bs4 で NavigableString だけを対象に置換すること。

## 4. 丸数字の光学中央

- `ol.ops li::before` と `.band .num` の `padding-bottom:1px` を撤去し、ズレを再調整（`display:flex` 維持・必要なら `padding-top` 0.5〜1px で追い込む）。**修正後、PDF を 2 倍相当で拡大レンダリングした画像（該当部分の crop）で中央に見えることを目視確認**してから確定。

## 5. 文言削除

- 1章 ログイン手順の「（現在の名称は「落合コーポレーション様 デモ」です）」を丸ごと削除。移管後に名称が変わる注記も不要。

## 6. 画像を大きく

- **最重要**。単独画像のページは `max-height` を 105〜110mm 程度へ、2 枚縦積みページは 88〜92mm へ、ページごとに調整（CSS 一律でなく、`style=""` のページ個別上書きで良い）。
- 判定基準: 管理画面スクショの**メニュー文字が読める**こと。かつフッター・下のボックスに衝突しない。全ページ視覚確認で 1 枚ずつ決める。

## 7. 「保存」ボタンの画像を追加

- 既存アセット（`../33-manual-assets/print/` の顧客編集・メタオブジェクト編集系スクショ）から**保存ボタン付近を Python(PIL) で crop** し、`../33-manual-assets/print/90_save-button-crop.jpg` 等として保存（元画像は変更しない。PIL が無ければ `pip install pillow` は禁止、`sips -c` で crop）。可能なら PIL で赤枠を描く。
- 掲載箇所: 1章「操作するときの3つのお願い」と、3章「割引率の表を編集する」の保存手順の近く。キャプション「保存ボタンは画面右上に出ます」。

## 8. 長文ボックスの改行

- note／ok ボックス内が **3 文以上**の場合、文単位で `<br>` を入れるか「・」の箇条書きに割る（例: A-2 の「すでに入っているご注文の金額は変わりません」ボックス）。1〜2 文のボックスはそのまま。

## 9. 「画像がない商品」前提の記述を事実に合わせて削除・訂正

- **事実**: 商品登録は落合様が画像込みで行う（質問 No.14・2026-07-28 決定）。「画像が無い商品」は現在のサンプルデータだけの一時的な状態。
- 2章 A-1 手順の「画像がまだ無い商品は「下書き」のまま にします」を削除し、「画像も登録してから公開します」に置換。
- 2章 A-3 内の「画像がない商品」関連の記述（非公開運用・G-6 由来）を削除。A-3 は「売るのをやめる・一時的に隠す」の説明に純化する。
- 他ページに同種の記述がないか全文 grep で確認して除去。
