## 全体ルール（前回と同じ、厳守）

- 文末は句点「。」。日本語と英数字の間に半角スペースを入れない。
- 節参照は `P.<span class="pref" data-ref="sec-xx"></span>` 形式（結合時に自動解決）。
- 新規ページは既存ページの HTML 構造（band／lead／ops／figs／note／ok／foot）をそのままなぞる。フッターは `<span>0 / 0</span>` 形式で置けば採番は結合スクリプトがやる。
- 画像は `../33-manual-assets/print/` 配下。**新規追加した画像は大きく**（単独 max-height 105〜110mm、2枚積み 88〜92mm、ページごとに調整）。
- 修正後は必ず単体 PDF 化 → 全ページ Read で視覚 QA（はみ出し・フッター衝突・改行・画像可読性）。問題ゼロまで繰り返し、ページごとの OK 一覧を報告に含める。
