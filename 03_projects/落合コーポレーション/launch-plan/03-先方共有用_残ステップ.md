## 1. 全体像

公開までの作業を **2つの流れ** に分けて並行で進めます。

- **A. サイト構築（Shopify）**: 注文・請求書・送料・決済などの機能面。デザインの確定を待たずに進められます。
- **B. デザイン**: トンマナ（色・フォント・雰囲気）の確定と反映。ホームページ制作会社様には、こちらで確定したデザインに合わせていただく方針です（第4回MTG合意事項）。

目標: **7月末の公開**（第4回MTGで共有済みの目標）。

```
A. サイト構築:  仕様の最終確認 → 本番環境への移行・設定 → 全体テスト → 受入確認 → 公開
B. デザイン  :  B2C=案B確定済み・素材待ち ／ B2B=デザイン案作成→ご選定 → サイトへ反映 → HP制作会社様へ共有
```

## 2. A. サイト構築（Shopify）の残ステップ

### Step A-1. 仕様の最終確認・工程表のご合意（〜7/21目安）

- 公開までの詳細工程表（本資料の元となる詳細版）を作成し、**宏樹様にご確認・ご了承をいただく**
- 未確定事項の確認依頼を一括でお送りする（→ 下記「4. お願いしたい事項」）
- 技術検証（本番ストアへの移行方式、クレジットカード決済の審査期間、佐川急便の送り状連携方式 等）

### Step A-2. 本番環境の構築（7/21〜7/24目安）

- Shopify 本番プランのご契約（ご契約名義の確認が必要です）
- 現在の開発環境から本番ストアへ移行(テーマ・商品・顧客・連携アプリの再設定)
- 独自ドメインの設定
- マネーフォワード請求書との本番連携(貴社アカウントでの認証)
- 請求書の自動発行・締め処理の本番設定

### Step A-3. 決済・送料・配送の設定(7/22〜7/25目安)

- クレジットカード決済(Shopify Payments)の申請・審査 ※審査期間により公開後の有効化になる可能性あり
- 銀行振込・代金引換の本番確認
- B2C送料(8,000円以上無料 等)・B2B送料(地域別の無料条件)の設定
- 佐川急便の送り状連携・在庫管理の設定

### Step A-4. ページ・商品データの整備(7/22〜7/26目安)

- トップページ・会社概要・お問い合わせ・法定ページ(特定商取引法表記 等)の作成
- 注文確認・発送通知などの自動メール文面の整備
- 実商品データの登録(商品マスタご提供後)・画像のない商品の非公開設定(第4回MTG合意)
- B2B掛率の実数値の反映(数値ご提供後)

### Step A-5. 全体テスト(7/27〜7/29目安)

- B2C(一般のお客様)・B2B(法人様)それぞれについて、注文〜請求書発行までの操作を1アクションずつ確認するテストシナリオ(約100ケース)を実施
- 不具合の修正・再テスト

### Step A-6. 受入確認・公開(7/29〜7/31目安)

- 貴社での受入確認(チェックリストをお渡しし、実際に操作いただきます)
- テストデータの削除・本番データの最終確認
- 操作マニュアル等のドキュメント納品
- パスワード保護の解除 = **サイト公開**

### 関連する運用予定

- **管理画面の使い方レクチャー**(対面・7/20の週を軸に日程調整中、古谷より別途ご案内)

## 3. B. デザインの残ステップ

### B2C(一般のお客様向け)

1. ✅ デザイン案のご選定 — **案Bにて確定済み**(7/15にご連絡いただきました。ありがとうございます)
2. ご指定カラー(Evolution Green 基調・Passion Red 差し色・黒ヘッダー)の反映
3. **素材のご提供待ち**: 会社ロゴ画像・メインビジュアル用のシャトル静止画
4. おすすめ商品スライダーの設置・キャッチコピー「FEEL THE HEARTBEAT」の反映
5. 実商品画像の反映(商品データのご提供と連動)
6. 反映後のご確認

### B2B(法人様向け)

1. B2Cと同じ要領でデザイン案を複数作成し、ご共有(第4回MTG合意)
2. ぽぽ様・宏樹様にてご選定(お電話・LINE通話でのご相談も可能です)
3. 選定案をサイトへ反映・ご確認
4. 確定したデザイン一式をホームページ制作会社様へ共有し、HP側を合わせていただく

## 5. 主なリスクと対応方針

| リスク | 対応方針 |
|---|---|
| クレジットカード決済の審査が公開日に間に合わない | 銀行振込・代引きで先行公開し、クレカは審査完了後に有効化 |
| 商品マスタ・掛率のご提供が遅れる | 提供済みデータで公開し、後日一括差し替え(B2Bのみ公開を遅らせる選択肢もあり) |
| B2Bデザインの確定が遅れる | 機能面を先に公開し、デザインは公開後に反映(要ご相談) |
| 佐川連携の構築が想定より重い | 初期は注文データの手動書き出し→e飛伝取込の暫定運用でカバー |
