# B2C / B2B テストシナリオ（1アクション単位）ドラフト

作成: 2026-07-14 ／ ステータス: **ドラフト（naru 未承認）**
粒度: 1行 = 1アクション（操作）+ 期待結果。通しテスト時は上から順に実行。
凡例: 【境界】= 境界値テスト ／ 【分離】= B2C/B2B分離検証 ／ 【本番のみ】= Dev storeでは検証不可・本番ストアで実施

環境前提:
- B2C テストアカウント: 一般会員（metafield なし）
- B2B テストアカウント: corp-a（groupA）/ corp-b（groupB）/ corp-custom（custom_overrides あり）/ corp-noterms（payment_terms 未設定）
- 支払区分: ①かけ20日締め（20th）/ ②末締め（eom）/ ③都度（prepaid）
