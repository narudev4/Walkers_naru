# 佐川連携 3方式比較（2026-08-03）

調査主体: sagawa-spike（公式サイト・App Store・公式ヘルプベース。未確認項目は明記）。
対象工程: H-1（連携方式の決定）。前提: 佐川と法人契約あり（No.54①・第7回MTG）・毎日集荷あり（naru 確認）・Shopify Basic。

## 結論（推奨: Ship&co）

既存の法人契約運賃と集荷体制をそのまま使えるのは Ship&co と API 直結のみ。**プラスシッピングは発送時に同社の配送料率（Platinum／Gold／Silver）に置き換わり、既存契約運賃が使えない**ため、毎日集荷の荷主には不利になる可能性が高い。API 直結は佐川の送り状発行 API が非公開（個別交渉・仕様書は契約後・承認1〜2週間＋開発工数全額自社負担）で本案件には過剰。

## 判断に必要な残情報（No.54 の後日共有と合わせて先方に確認）

1. 現在の送り状発行システムの正式名称と、佐川のお客様コード（12桁）。送り状右下・運賃請求書・スマートクラブ「ご契約内容の確認」で確認可能。
2. 現行の契約運賃（サイズ別・地域別）。プラスシッピング料率との比較に必要。
3. 月間の想定出荷件数（Ship&co の料金レンジ確定に必要）。
4. 代引・クール便・複数個口の利用有無。
5. 入金前発送の有無（請求書払いで「支払い保留」の注文を配送アプリが同期するかの事前検証が要る）。

## 設計上の確認結果（ローカルコードで確認済み 2026-08-03）

- Shopify 公式「custom items は配送アプリの自動処理不可」の懸念について、当方の Draft Order 生成は**バリアントベース**（`variantId` + `appliedDiscount`。workers/src/handlers/createDraftOrder.js:233-242）であり、カスタム品目は使っていない。この懸念は該当しない。
- **★新発見**: `appliedDiscount` のタイトルが「B2B卸価格 (掛率60%)」形式で**掛率数値を含む**（同ファイル242行目）。請求画面・請求書に表示される可能性があり、掛率非表示方針（第5回MTG）と衝突しうる。実機確認のうえタイトル変更（例:「御社価格適用」）を検討する。
