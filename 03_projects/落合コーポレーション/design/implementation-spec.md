## Task 3: B2B 値引きロジック

### 確定仕様（discount-system.md §11 + 実機検証済み）

#### データモデル（✅ 実装・検証済み）

```
Customer metafield (namespace: b2b):
  - customer_type:    "individual" | "corporate"
  - discount_group:   "A" | "B" | "C" | "custom"
  - custom_overrides: JSON {"racket": 0.55, ...}

Product metafield (namespace: b2b):
  - category:  "racket" | "wear" | "shoes" | "ball" | "string" | "accessory"
  - sport:     "badminton" | "tennis" | "pickleball"

Metaobject: discount_matrix
  - group:          "A" | "B" | "C"
  - category:       "racket" | "wear" | ...
  - discount_rate:  0.0 - 1.0
```

#### 掛率計算ロジック（✅ discountEngine.js 15テスト全パス）

```
最終掛率(customer, product) =
  customer.custom_overrides[product.category]   // 個別優先
    ?? discount_matrix[customer.group][product.category]  // グループ×カテゴリ
    ?? 1.0  // デフォルト正価
```

#### 購入フロー（Draft Order方式・✅ 実機検証済み）

```
[営業/システム] 顧客の発注を受ける
  → discountEngine.js で掛率算出
  → createDraftOrder.js で priceOverride 適用の Draft Order 作成
  → Draft Order → 通常注文に変換（Manual Payment = 支払保留）
  → MF請求書API連携（Task 1のパイプライン）
```
