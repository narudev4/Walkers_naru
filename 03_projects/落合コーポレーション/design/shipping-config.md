# 送料設定チェックリスト

Shopify 管理画面「設定 > 配送と配達」で手動設定する。
B2C / B2B で別プロファイルを作成し、それぞれ以下のルールを設定する。

---

## B2C 送料（一般顧客向け）

### 国内配送（本州・四国・九州 ※沖縄・北海道除く）

- [ ] 8,000円以上 → 送料無料
- [ ] 8,000円未満 → 550円

### 沖縄・北海道

- [ ] 一律 1,500円（金額条件なし）

### その他

- [ ] 小口商品にも送料を適用する（「この配送料にはアイテムの重量を使用する」等で小口除外しない）

---

## B2B 送料（法人顧客向け）

### 国内配送（本州・四国 ※九州・北海道・沖縄除く）

- [ ] 下代 20,000円以上 → 送料無料
- [ ] 下代 20,000円未満 → 550円

### 九州・北海道

- [ ] 30,000円以上 → 送料無料
- [ ] 30,000円未満 → 550円

### 沖縄

- [ ] 50,000円以上 → 送料無料
- [ ] 50,000円未満 → 550円（要確認: 沖縄の送料未満時の金額を先方に確認）

### その他

- [ ] 小口商品にも送料を適用する

---

## 設定手順メモ

1. **配送プロファイル分離**: B2C 用はデフォルトプロファイル、B2B 用はカスタムプロファイルまたは B2B カタログの配送設定で分ける
2. **配送ゾーン**: 「本州・四国」「九州・北海道」「沖縄」の3ゾーンを作成（都道府県単位で割り当て）
3. **条件付き送料**: 各ゾーンで「価格に基づく配送料」を使い、閾値と料金を設定
4. **B2B の "下代" 基準**: B2B Discount Function 適用後の金額が閾値判定に使われるか、適用前の上代で判定されるかを要検証

## 確認事項

- [ ] 沖縄 B2B 送料未満時の金額（550円で良いか、別金額か）を先方に確認
- [ ] B2B 送料の閾値は「下代（割引後）」基準か「上代（定価）」基準かを確認
- [ ] 離島対応が必要か確認
