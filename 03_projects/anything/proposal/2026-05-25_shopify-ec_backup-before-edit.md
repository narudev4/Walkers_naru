## 1. 提案概要
本提案の目的
6月の実店舗オープンと同時に EC サイトを立ち上げ、店舗とオンラインの両輪で販売機会を最大化します。Shopify を基盤に SAFARI のような lux-minimal な世界観を実現し、一点物のヴィンテージ古着を求める顧客にブランド体験を届けます。「補助金に依存せず即着手するフェーズ」と「補助金採択後に拡張するフェーズ」の二段構えにより、リスクを抑えながら段階的に DX を推進します。
ターゲット： B2C（ヴィンテージ古着の一点物を求める国内顧客／将来的に海外顧客）
特徴： ① 6月の実店舗オープンと同時に EC 公開を実現する短期立ち上げ　② SAFARI を参考にした lux-minimal なモノクロベースのブランドデザイン　③ 補助金活用の二段構え（Phase 1は補助金不要・Phase 2は採択後に拡張）
ローンチ目標： 2026年6月（実店舗オープンと同期して EC を公開）
期待効果： 実店舗オープンと同時に EC を公開することで販売機会の損失を防ぎ、画像・商品情報の更新を内製で運用可能な構成に整えます。補助金活用により実質負担を抑えつつ、将来の公式LINE 連携・海外展開を見据えた拡張性を確保します。

## 2. 現状整理
業界・市場の現状
貴社は2026年6月に東京で実店舗オープンを予定する、1970〜1990年代のヴィンテージ古着を扱うセレクトショップです。実店舗の集客と並行し、EC による販売チャネルを早期に確立する必要があります。一点物のヴィンテージ古着は在庫が「1点限り」という性質上、店舗と EC で在庫を同期させる仕組みが事業継続の鍵となります。

| 課題 | 詳細・現状 |
|---|---|
| 6月オープンに向けた EC 立ち上げ手段が未確立 | 実店舗オープンが目前に迫る中、EC 構築の具体的な方針・体制が固まっていない。店舗オープンに EC が間に合わないと、最も売上機会の大きい立ち上げ期を逃すリスクがある |
| 一点物の在庫管理（店舗⇔EC同期、SOLD管理） | 古着は一点物のため在庫数=1。店舗で売れた商品が EC に残ったままだと二重販売のリスクが発生する。撮影・出品・SOLD反映までを店舗運用に組み込んだフローが必要 |
| 他社の見積もりが割高（2年分のサーバー代込で約140万円） | 前提として提示された他社見積もりは、ランニングコストを過剰に含むなど価格構造に課題がある。Shopify と適切な構成設計により、総額・ランニングコストの双方を最適化する余地が大きい |

## 3. 提案ソリューション
支援コンセプト
支援名称（仮称）：Shopify EC構築＋デジタル化補助金活用支援
Shopify の Horizon テーマをベースに、SAFARI のような lux-minimal な世界観を実装した EC サイトを構築します。一点物の在庫管理は Shopify 標準機能で自動化し、撮影〜出品〜SOLD 表示までを店舗運用に組み込んだフローを設計します。Phase 1（即着手・補助金不要）で6月のオープンに間に合わせ、Phase 2（補助金採択後）で公式LINE 連携・多言語対応・海外配送など拡張機能を段階的に追加します。

主要機能一覧

| 機能カテゴリ | 概要 |
|---|---|
| Shopify EC サイト構築（Horizon + SAFARI 風カスタマイズ） | 公式無料テーマ Horizon をベースに、モノクロ基調・サンセリフ書体・正方形商品グリッドで lux-minimal な世界観を実装。PC・スマートフォン・タブレットに完全対応 |
| 一点物在庫管理・SOLD 自動表示 | Shopify 標準の在庫管理で在庫数=1 を「売り切れ」自動表示。店舗で売れた商品は管理画面から即時に SOLD OUT 化でき、二重販売を防止 |
| 撮影・出品フロー設計＋運用研修 | 買い取り時の撮影ガイドライン・商品データ入力テンプレートを整備。店舗スタッフが自分達で出品・更新できるよう操作研修を実施し、内製運用を実現 |
| 公式 LINE 連携（Phase 2） | 公式 LINE での会員ログイン連携・新着商品通知・SOLD アラートを実装。実店舗の常連顧客を EC に誘導し、リピート率を高める |
| 多言語化・海外配送対応（Phase 2） | Shopify Markets による英語切替・多通貨表示・海外配送設定を実装。海外のヴィンテージ愛好家に対する販売チャネルを確立 |

## 4. EC構築・運用フロー
1. ご契約： 契約書締結・要件定義フェーズ着手金のお支払い
2. 要件ヒアリング： 商品カテゴリ・価格帯・撮影体制・店舗運用フローのヒアリング。ブランド世界観の方向性も併せて確認
3. Shopify 環境構築： ストア開設・Horizon テーマ設定・コレクション（TYPE別／ERA別／BRAND別）の設計
4. デザイン適用（SAFARI 風カスタマイズ）： カラー・フォント・ロゴ・ヒーローセクションのカスタマイズ。モノクロ基調＋アクセントカラーで lux-minimal な世界観を構築
5. 商品データ・画像投入： 初期商品の登録・撮影画像の整備。買い取り時の撮影フローと連動した運用ルールを整える
6. テスト・運用研修： 動作確認・店舗スタッフ向けの管理画面操作研修を実施。商品追加・SOLD 切替・問い合わせ対応を内製化
7. 本番公開（6月実店舗オープン同期）： EC サイト本番公開。実店舗オープンとあわせて告知し、両チャネルで販売をスタート
