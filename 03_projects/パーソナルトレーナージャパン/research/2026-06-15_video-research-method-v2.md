# 5-1 たたき台: 全動画調査 ＋ 区間抽出 ＋ マッチング（方法 v2）

> ⚠️ **ブレスト用たたき台（作業メモ・2026-06-15）。確定事項ではない。** 別セッションで叩いて詰める。確定したら真理源スプシ「動画マッチング」タブ＋ `app/lib/diagnosis/video-matching.ts` へ昇格。

## 目的（6/15 MTG決定の具体化）
- 調査範囲を **59本 → チャンネル全動画（約450〜467本）** へ拡大
- 各エクササイズの **IN/OUT秒（区間）** をAIで出力 → 枝光様が確認
- 結果画面マッチング（5-2 複数区間）が使う **データ構造＝簡易要件** を定義

## 以前の方法（参考資料タブから再構成）
※専用ドキュメントは無し。質問シート「参考資料」タブ（59本）と「動画マッチング」タブが成果物。

- 入力：動画59本（`# / 動画ID / タイトル / リンク / 長さ秒 / 長さ分秒 / 抽出動作数`）
- **`抽出動作数` 列がカギ** ＝ 各動画からAIが抽出したエクササイズ動作数とみられる。例: 腰痛ストレッチ `9RnUdSkBUb4`=7、猫背 `nf4FEHAnsp8`=5、坐骨 `2yEeB6YhwDU`=2、**かかと落とし `2ORAIV6S0os`=0**、スクワット解説 `RkAVVkldbXI`=0
- 抽出動作を12課題（動作×原因マトリックス）へマッチング → 「動画マッチング」タブの第1/第2候補
- **弱点**：(a) 区間(IN/OUT)未取得、(b) **ダイエット/解説系は抽出0が多い**（機能・筋の言及が字幕に無く拾えない＝MTGの課題そのもの）、(c) 手順が未文書化

## 強化版の方法（ドラフト）
1. **全動画リスト取得**：心身健康倶楽部チャンネルの全動画 ID/タイトル/尺/字幕有無を取得（YouTube Data API の uploads playlist、または youtube MCP）。参考資料タブを450本規模に拡張。
2. **区間つき抽出**：各動画の字幕(transcript)＋タイトルをLLMに渡し `[{動作名, start秒, end秒, 対象筋, 効果, 信頼度}]` を構造化出力。←「抽出動作数」を「動作＋区間」に進化させる。
3. **ダイエット文脈の補正**：機能・筋の言及が薄い動画は信頼度Lowで要レビュー扱い。既存動画は修正しない（MTG方針）。新規撮影で言語化（PTJ側）。
4. **課題マッチング**：抽出動作を12課題へスコアリング（推奨筋・効果キーワード＋意味類似）。課題ごとに上位区間を第1/第2候補に。
5. **枝光様確認**：各動画のIN/OUT秒を一覧出力 → 枝光様が正誤確認（誤りは本人が動画を見て修正）。

## マッチングの簡易要件（5-2・結果画面が使う）
- データ構造：`課題 → [{ videoId, start, end, label, score, rank }]`
- **1動画を複数課題・複数区間で再利用可**（同一IDで区間違い）
- 1課題に複数区間（複数動作）も可 → 5-2 の複数区間＋スキップ
- 「問題なし」時の予防動画も同じ枠
- 出力先＝「動画マッチング」タブ（真理源）→ `video-matching.ts` へ転記（現状の `課題→URL文字列` を `{id,start,end}` 構造へ拡張）

## ブレストで決めたい論点
