## 1. 提案概要

**本提案の目的**

海外在住の富裕層が、日本の不動産をオンラインで検索・内覧・契約できるプラットフォームを構築します。
第1フェーズとして東京都の物件に特化したMVPを開発し、段階的に全国展開を目指します。

- ターゲット： 海外在住のビジネスエリート層・富裕層（1〜2億円規模の物件をキャッシュ購入できる層）
- 特徴： 多言語・多通貨対応の物件検索、カレンダー連携によるオンライン内覧予約（タイムゾーン自動調整）、物件ごとのチャットによる担当者対応
- ローンチ目標： 要件定義完了後、約2〜3ヶ月でMVPリリース
- 期待効果： 海外からの物件購入プロセスをオンライン化し、渡航なしで内覧から契約手続きまで完結できる環境を実現

## 2. 現状整理

**業界・市場の現状**

初回MTGで伺った内容をもとに、解決すべき課題を以下に整理します。

| 課題 | 詳細・現状 |
|------|-----------|
| 物件情報の言語・通貨の壁 | 海外居住者向けに多言語・多通貨で物件を検索できるサービスが不足しており、情報取得に大きな障壁がある |
| 内覧の物理的制約 | オンライン内覧の仕組みがなく、物件確認のために日本への渡航が前提となっている |
| タイムゾーン・コミュニケーションの障壁 | 国際間の時差による日程調整の難しさと、言語の壁によるスムーズな意思疎通の困難さがある |

## 3. 提案ソリューション

**支援コンセプト**

支援内容：不動産仲介プラットフォームの設計・開発・導入支援

ユーザー（海外居住者）・担当者・管理者の3者が利用するWebプラットフォームを構築します。
ユーザーは多言語・多通貨で物件を検索し、チャットで問い合わせ、カレンダー連携でオンライン内覧を予約できます。
担当者は担当物件の管理と顧客対応を効率化し、管理者は全体の運営を一元管理できます。
クライアント様自身がAI駆動開発の研修を受けることで、リリース後の軽微な修正・改善を自社で行える体制を整えます。

**主要機能一覧**

| 機能カテゴリ | 概要 |
|-------------|------|
| 物件検索・詳細表示 | 多言語・多通貨で物件を検索・閲覧。エリア・価格帯・物件種別で絞り込み可能 |
| オンライン内覧予約 | カレンダー連携でタイムゾーンを自動調整。担当者が現地からビデオ配信で内覧を実施 |
| チャット機能 | 物件ごとに担当者とメッセージをやり取り。資料請求や質問にリアルタイムで対応 |
| お気に入り・資料請求 | 気になる物件を保存し、ワンクリックで資料請求。ユーザーの検討状況を可視化 |
| 管理ダッシュボード | 担当者向け（担当物件・顧客対応・スケジュール管理）とシステム管理者向け（物件・ユーザー・担当者の一元管理）の2種類を提供 |

## 4. 利用フロー

1. ユーザー登録： 居住国・タイムゾーンを設定してアカウントを作成
2. 物件検索・保存： 条件を指定して物件を検索し、気になる物件をお気に入り登録
3. 問い合わせ： チャットで担当者に質問・資料請求
4. オンライン内覧： カレンダーから希望日時を選択。担当者が現地からビデオ配信で物件を案内
5. 契約手続き： 条件合意後、契約書類の取り交わしを進行

## 5. システム構成

**開発形態**

- プラットフォーム： ブラウザベースのWebアプリケーション
- 対応デバイス： PC・スマートフォン・タブレット（レスポンシブデザイン）
- モバイルアプリ： 初期フェーズでは不要（Webで完結）

**推奨技術スタック**

- フロントエンド： Next.js（React） — 高速なページ表示、SEO対応、多言語ルーティングに最適
- バックエンド： TypeScript（Node.js） — フロントエンドと言語を統一し開発効率を向上
- データベース： PostgreSQL — 多言語データの柔軟な管理、地理情報検索に対応
- インフラ： Vercel + AWS — 高速配信とスケーラビリティの両立

**セキュリティ対策**

- SSL/TLS通信暗号化、ユーザー認証にJWT採用
- 個人情報のアクセス制御とログ管理
- 定期的なバックアップと障害時の復旧体制

## 6. 開発スケジュール

AI駆動開発により、段階的にMVPを構築します。要件定義で確定した仕様に基づき、3フェーズに分けて開発を進めます。各フェーズ完了時にレビューを行い、方向性を確認しながら進行します。

| フェーズ | 期間 | 主な作業内容 |
|---------|------|-------------|
| 要件定義フェーズ | 約2〜3週間 | 要件定義・画面設計・DB設計・UIデザイン |
| 開発フェーズ | 約1〜1.5ヶ月 | 環境構築・認証基盤・全20画面の開発・外部連携（多言語・カレンダー） |
| テスト・リリースフェーズ | 約2〜3週間 | 結合テスト・ユーザー受入テスト・本番デプロイ |
