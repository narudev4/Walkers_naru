## 1. 提案概要

**本提案の目的**

貴社では、問い合わせ対応（パーツ・ケース適合、在庫確認、初期メンテナンス）に年代ごとのExcel・PDFを都度参照する業務と、11社のディーラーから届くPSI帳票の分析業務に、多くの工数がかかっています。本提案では、データの正規化・一元化を土台として、検索・AIチャットによる問い合わせ対応支援と、柔軟な分析ができるダッシュボードを構築します。

- **ターゲット：** ディーラーサポート・カスタマーサポート担当者（4〜5名）、および売上データを分析する経営層・担当者
- **特徴：** 散在するデータを一元化し、検索とAIチャットで即座に回答を引き出せます。11社分のPSI帳票を柔軟に分析できるダッシュボードと、自然言語での分析にも対応します。部品番号等の高機密データは、アクセス権限を持つ担当者のみが参照できるよう設計します。
- **ローンチ目標：** 要件定義完了後に確定（初期リリースまで約3〜4ヶ月を想定）
- **期待効果：** 問い合わせ対応にかかる調査時間の短縮と、店舗×モデル単位までドリルダウンできる分析の実現を見込みます

## 2. 現状整理

**業界・市場の現状**

貴社は日本法人として25〜26名の体制で運営されており、ディーラー経由の卸売が主軸で直接販路を持たれていません。問い合わせ対応とデータ分析の担当者は少人数のため、一人ひとりの生産性向上と、属人化した専門知識の継承が課題となっています。

| 課題 | 詳細・現状 |
| --- | --- |
| 問い合わせ対応の分散データ | 年代・型番ごとに分かれたExcel・PDFを都度手作業で参照。ハードケース適合表は875行×235列に及び、確認に時間がかかっています |
| PSI帳票分析の柔軟性不足 | 11社のディーラーから毎月届くPSI帳票（200〜500行/社）をPowerBIで分析していますが、定型約20種類の分析に限られ、店舗×モデル単位の柔軟な分析ができません |
| データ基盤の未整備・機密性 | パーツ構成（BOM）データは部品番号を含む高機密情報で、外部流出への配慮が必要です。データ形式もExcel・Word・PDFに分散しています |

## 3. 提案ソリューション

**支援コンセプト**

支援内容：AI活用型 問い合わせ対応支援・データ分析基盤の構築

散在するデータをまず正規化・一元化し、その上に「検索・AIチャット」と「分析ダッシュボード」を構築します。事実確認（在庫・適合状況等）はシステムで正確に行い、回答文章の生成や柔軟な分析はAIが担う、ハイブリッドな構成とします。

**主要機能一覧**

| 機能カテゴリ | 概要 |
| --- | --- |
| 適合・在庫検索 | 型番・パーツ名・年代で検索し、適合パーツ・適合ケース・販売状況を参照元付きで一括表示します |
| AIアシスタント（問い合わせ回答支援） | 自然文の問い合わせに対し、社内データを参照して回答文とメール返信文の下書きを生成します |
| 売上・在庫分析ダッシュボード | 11社のディーラーから届くPSIデータを集計し、期間・ディーラー・モデル別に分析します。自然言語での自由な分析にも対応します |
| データ正規化・マスターデータ化 | 散在するExcel・Word・PDFを構造化し、検索・分析の共通参照元として整備します |
| AI活用研修・伴走コンサルティング | Claude等のAI活用基盤を整備し、社内メンバーが自走してAIを使いこなせるよう研修・伴走支援を行います |

## 4. 問い合わせ対応・データ活用フロー

1. **データ正規化：** 散在するExcel・Word・PDFを構造化データに整理します
2. **検索・参照：** 担当者が型番・パーツ名で検索し、適合パーツ・ケース・在庫状況を確認します
3. **AI回答生成：** 問い合わせ内容をAIチャットに入力し、参照元付きの回答文を生成します
4. **メール下書き作成：** 生成した回答からメール返信文の下書きを自動作成します
5. **分析・改善：** 蓄積した問い合わせ履歴とPSIデータをダッシュボードで分析し、対応品質と業務効率を継続的に改善します

## 5. システム構成

**開発形態**

- **プラットフォーム：** ブラウザベースのWebアプリケーション
- **対応デバイス：** PC・スマートフォン・タブレット（レスポンシブデザイン）
- **モバイルアプリ：** 初期フェーズでは不要（Webで完結）

**推奨技術スタック**

- **フロントエンド：** Next.js（検索・チャット・分析画面を一つの基盤で構築でき、開発速度と保守性のバランスが良いため）
- **バックエンド：** Next.js API Routes + Claude API（自然言語での回答生成・分析にAnthropic社のClaudeを使用するため）
- **データベース：** PostgreSQL等のRDB（構造化したマスターデータを正確に管理するため）
- **インフラ：** Vercel等のクラウドホスティング（社内向け中規模システムに適し、運用コストを抑えられるため）

**セキュリティ対策**

- BOM（部品構成）等の高機密データは、アクセス権限を持つ担当者のみ参照可能とする権限管理を実装します
- 通信は全てHTTPSで暗号化し、社内ネットワークまたは認証基盤経由でのみアクセス可能とします
- 高機密データについては、外部への出力（ダウンロード・エクスポート）を制限する運用ルールを設けます
