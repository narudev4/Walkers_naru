## 1. 提案概要

**本提案の目的**

髙橋様には、問い合わせ対応（パーツ・ケース適合、在庫確認、初期メンテナンスの確認）に年代ごとのExcel・PDFを都度参照して対応されていると、また、ディーラーから届く販売データを柔軟に分析しきれていない、とお伺いしました。本提案では、これらのデータを整理したうえで、誰でも使える検索・AIチャットのツールと、AIを使いこなすための研修・伴走支援を、両方の軸でご提案します。

**ターゲット：** 問い合わせに対応される方、および販売データを分析される経営層・ご担当者

**特徴：** 年代ごとに分かれたExcel・PDFのデータを一元化し、検索するだけで正確な情報にアクセスできます。問い合わせ内容を入力すると、社内データを参照した回答文やメール返信文の下書きをAIが作成します。Claude Code研修により、ツールの範囲を超えて業務全体でAIを使いこなせるようになることを目指します。

**ローンチ目標：** 要件定義完了後に確定（初期リリースまで約3ヶ月を想定）

**期待効果：** 問い合わせ対応にかかる時間の短縮と、より柔軟なデータ分析の実現を見込みます。

## 2. 現状整理

**髙橋様からお伺いした現状**

主な課題は以下の3点です。

| 課題 | 詳細・現状 |
| --- | --- |
| 問い合わせ対応に時間がかかる | パーツ・ケースの適合、在庫確認、初期メンテナンスの問い合わせを、年代ごとに分かれたExcel・PDFを都度手作業で参照して対応しているとのことでした |
| データ分析が定型的な内容に限られる | ディーラーから毎月届く販売データを分析していますが、決まった分析しかできず、店舗×モデル単位のような柔軟な切り口では見られないとのお話でした |
| 対応できる人が限られている | 問い合わせ対応は4〜5名の少人数で担当されており、パーツの互換性やメンテナンスの知識が一部の方の経験に依存しているとのことでした。その方が対応できないと、同じ品質で答えられない状況とのお話でした |

## 3. 提案ソリューション

**支援内容：誰でも使えるツールと、AIを使いこなす力を、両方からご支援**

ご提案には2つの軸があります。

**1. 誰でも使える検索・AIチャットのツール（システム開発）**

年代ごとに分かれたExcel・PDFのデータを一つの場所に整理し、検索するだけで正確な情報にアクセスできる画面を作ります。例えば「このギターに合うハードケースは？」と検索すると、適合するパーツ・ケースの情報が、元のどのファイルを参照したかも含めて表示されます。問い合わせ内容を入力すると、社内データを参照して回答文やメール返信文の下書きを作成する機能も用意します。裏側ではAIを使いますが、使う方はいつも使っている検索や入力の操作をするだけで済みます。販売データについても、決まった集計だけではなく、店舗×モデルのような自由な切り口で分析できるダッシュボードを作ります。

**2. AIの使い方を学び、業務全体で使いこなせるようになる（Claude Code研修・伴走支援）**

ツールでカバーする範囲を超えて、Claude Codeそのものを使いこなせるようになるための研修・伴走を行います。問い合わせ対応だけでなく、日々の分析や資料作成など、幅広い業務にAIを活用できるようになることを目指します。これにより、知識が一部の方に依存している状態を、AIを使えば誰でも同じ水準で対応できる状態に変えていきます。

弊社では、まず1の土台を整えたうえで、2の研修・伴走を並行して進めることをご提案します。システムがなければ、AIは正確な在庫・適合状況を答えられません。研修がなければ、そのシステムを使いこなして業務に活かす力が育ちません。

**主要機能一覧**

| 機能カテゴリ | 概要 |
| --- | --- |
| 適合・在庫検索 | 型番・パーツ名・年代で検索し、適合するパーツ・ケースの情報と在庫状況を、参照元のファイルも含めて表示します |
| AIアシスタント（問い合わせ回答支援） | 問い合わせ内容を入力すると、社内データを参照した回答文やメール返信文の下書きを作成します |
| データ正規化・マスターデータ化 | 年代ごとに分かれたExcel・PDFのデータを整理し、検索・分析の共通の参照元として整備します |
| 売上・在庫分析ダッシュボード | 決まった集計だけでなく、店舗×モデルのような自由な切り口で販売データを分析できます |
| Claude Code研修・伴走支援 | ツールでカバーする範囲を超えて、Claude Codeを使いこなし業務全体でAIを活用できるようになるための研修と伴走を行います |

## 4. 問い合わせ対応・データ活用フロー

1. **データ正規化：** 年代ごとに分かれたExcel・PDFを構造化データに整理します
2. **検索・参照：** 担当者が型番・パーツ名で検索し、適合するパーツ・ケース・在庫状況を確認します
3. **AI回答生成：** 問い合わせ内容をAIチャットに入力し、参照元付きの回答文を生成します
4. **メール下書き作成：** 生成した回答からメール返信文の下書きを自動作成します
5. **分析・改善：** 蓄積した問い合わせ履歴とデータをダッシュボードで分析し、対応品質と業務効率を継続的に改善します

## 5. システム構成

**開発形態**

- プラットフォーム： ブラウザベースのWebアプリケーション
- 対応デバイス： PC・スマートフォン・タブレット（レスポンシブデザイン）
- モバイルアプリ： 初期フェーズでは不要（Webで完結）

**推奨技術スタック**

- フロントエンド： Next.js（検索・チャット・分析画面を一つの基盤で構築でき、開発速度と保守性のバランスが良いため）
- バックエンド： Next.js API Routes + Claude API（画面と生成AIの処理を一体的に開発するため）
- データベース： PostgreSQL等のRDB（構造化したデータを正確に管理するため）
- インフラ： Vercel等（社内向け中規模システムに適し、運用コストを抑えられるため）

**セキュリティ対策**

- 通信は全てHTTPS（暗号化通信）で保護し、社内ネットワークまたは認証基盤経由でのみアクセス可能とします
- アクセス権限を持つ担当者のみが、パーツ・在庫データを参照できるよう権限管理を実装します
- データのバックアップを定期的に取得し、障害時にも復旧できる体制を整えます
