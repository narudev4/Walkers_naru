**補助金を活用した業務特化型AIエージェント 導入・業務効率化支援のご提案**

靴のデザイン生成・営業・事務の各業務にAIを導入し、補助金を活用して定着まで一気通貫でご支援します

東峰貿易株式会社 小林 仁美 様 ／ 株式会社Walkers ／ 2026年6月17日

## 1. 提案概要

**本提案の目的**
靴のデザイン生成、営業（提案書作成・市場動向分析）、事務（請求書・納品書管理・資料作成）の各業務に、御社の業務に合わせてチューニングした業務特化型AIエージェントを導入します。汎用的なチャットツールをそのまま使うのではなく、専任エンジニアがいなくても使いこなせる形に仕立て、IT導入補助金の活用と導入後の研修・伴走まで一体でご支援します。

- **ターゲット**: 御社の営業部門・事務部門の皆様（専任エンジニア不在・現行業務はExcel中心）
- **特徴**: ①御社専用にチューニングした業務特化型AIエージェント（高性能なClaudeを推奨）／②既存ECサイトとの連携・ツール契約の見直しまで含めた全体最適／③補助金申請から導入後の操作研修・伴走までワンストップ
- **ローンチ目標**: IT導入補助金 第3次公募（締切2026年7月21日）に申請し、交付決定後（2026年9月以降）に構築・導入を開始する想定
- **期待効果**: デザイン案出し・提案書作成・市場分析・帳票処理といった反復業務にかかる工数を削減し、限られた人員でより付加価値の高い業務に時間を振り向けられる状態を目指す

## 2. 現状整理

御社は靴・雑貨の貿易およびECを運営されており、業務の時短・効率化のためAI活用をご検討されています。一方で社内に専任のエンジニアがおらず、現行業務はExcelを中心に運用されているため、高度なツールを導入しても現場が使いこなせるかが定着の鍵となります。本提案では、この実情を踏まえ『現場が使いこなせるAI』の構築と定着支援に主眼を置きます。

| 課題 | 詳細・現状 |
|---|---|
| ツール選定と定着の難しさ | AIで効率化したいが、多数のツールから自社に最適なものを選びきれない。汎用ツールは設定・運用の負担が大きく、専任エンジニア不在では定着が難しい。 |
| 靴デザイン制作の工数 | 新作デザインの案出しに時間がかかる。文章や既存画像からデザインを展開できる仕組みを求めている。 |
| 営業・事務の反復業務の負荷 | 営業では提案書作成・市場動向分析、事務では請求書・納品書の管理や資料作成に手作業が多く、限られた人員での負荷が高い。 |

## 3. 提案ソリューション

**支援内容：業務特化型AIエージェントの構築と定着支援**
御社の実際の業務フロー・データに合わせてチューニングしたAIエージェントを構築します。性能面で優れるClaude（Anthropic社）を中核に、PC操作をAIに代行させる技術や業務特化のカスタマイズを組み合わせ、現場がそのまま使える形でご提供します。さらに既存ECサイトとの連携も視野に入れ、ツールの追加・契約の見直しも含めて全体を最適化します。なお、Walkersが構築・チューニング・研修を担当し、御社には業務情報のご提供と運用をお願いする形で役割を分担します。

| 機能カテゴリ | 概要 |
|---|---|
| 靴デザイン生成（拡張プラン） | 文章からのデザイン案生成、既存画像からのバリエーション展開。画像生成は専用の画像生成AIを用います（Claudeは画像生成に非対応のため別構成）。 |
| 営業：提案書作成の自動化 | ヒアリング内容や商品情報をもとに提案書のドラフトを自動生成し、営業担当の作成工数を削減。 |
| 営業：市場動向分析・マーケティング支援 | 市場・競合・トレンド情報の収集と要約、施策立案のたたき台づくりを支援。 |
| 事務：帳票・資料作成の効率化 | 請求書・納品書の作成や整理、靴・雑貨の資料作成を効率化。PC操作の自動化も組み合わせる。 |
| 定着支援（研修・伴走） | 操作研修・マニュアル整備・導入後の伴走サポート。専任エンジニア不在でも運用が回る体制づくり。 |

## 4. 開発・導入スケジュール

交付決定前に発注・契約・お支払いをした費用は補助対象外となるため、まず要件定義のみを先行（自費）で実施し、補助金の交付決定後に構築・導入を進めます。小さく始めて段階的に拡張する方針です。

| フェーズ | 期間 | 主な作業内容 |
|---|---|---|
| Phase 1 | 2026年6月下旬〜7月 | 要件定義（業務フロー確認・効率化要件の確定）※準委任・自費先行 |
| Phase 2 | 〜2026年7月21日 | IT導入補助金 第3次公募への申請 |
| Phase 3 | 2026年9月（交付決定後）〜 | AIエージェントの構築・チューニング、既存EC連携 |
| Phase 4 | 構築完了後 | 操作研修・試運用・本格運用への移行と伴走サポート |

## 5. 補助金活用戦略

- **活用予定**: IT導入補助金（デジタル化・AI導入補助金）第3次公募
- **補助上限**: プロセス数・申請枠により変動。補助率は1/2〜2/3（申請区分・賃上げ要件で変動）
- **活用イメージ**: ソフトウェア購入費・クラウド利用料（例：ECのShopify 等）・導入関連費（要件定義／カスタマイズ／研修等の役務）を補助対象として組み立て。補助率は申請区分により1/2〜2/3で変動し、実質負担は総額の1/3〜1/2程度が目安。

**戦略的アプローチ**
- **費目の最適な組み立て**: 業務特化エージェントのフルオーダー開発は補助対象外となる場合があるため、補助対象（登録ITツール・クラウド利用料・導入役務）と対象外（追加開発）を切り分け、対象経費を最大化する構成を設計。
- **ツール費と役務費のバランス**: 採択されやすいツール費：役務費＝概ね1:1のバランスを意識し、導入関連費（上限あり）を有効活用。
- **申請から導入後までの伴走**: 申請書類の作成支援から、交付決定後の構築・実績報告・補助金支給までを一貫サポート（補助金申請サポートは成功報酬：採択額の8〜15%が目安）。
