# 録画用 営業送信スクリプト（先方共有デモ用）

- 対象: `/roleplay?demo=1` 録画ルート
- 想定尺: 2〜4 分
- 操作: naru（営業役）が下記 T1〜T7 を **順番に textarea へコピペ → 送信**。山田社長の返答は TTS で音声出力される。
- 営業部長相談（Q1〜Q3）は途中で 1〜2 回サイドパネルから投げる。
- 最後に「💡 振り返り FB を受ける」ボタンで講評を表示して締める。

> ✅ demo モードでは LLM 呼び出しなし。返答は `demo-scenario.ts` の決定論ルートから返るため、録画中の破綻リスクはゼロ。

---

## 想定ステージ遷移（7 ターン）

```
opening
  ↓ T1 名乗り＋簡単な用件（事業承継・退職金）
relevance
  ↓ T2 3 論点（自社株・退職金・運転資金）
pointExplanation
  ↓ T3 税理士領域と保険領域の切り分け
taxAccountant
  ↓ T4 息子・相続深掘り
hiddenConcern
  ↓ T5 無料診断面談の提案
softClose
  ↓ T6 日程提示（来週前半）
dateConfirm
  ↓ T7 日程確定（火曜11:00〜）
dateLocked
  ↓ 「💡 振り返り FB を受ける」
振り返り FB（review）
```

## 送信スクリプト

### T1: 名乗り＋簡単な用件（opening → relevance）

```
お忙しいところ恐れ入ります。Walkersの細谷と申します。事業承継や退職金のご準備の件で、1〜2分だけお話、よろしいでしょうか。
```

- 期待する山田の返答（relevance 候補）:
  - 「うちに何が関係するのか、もう少し具体的に聞かせてもらえますか？」
  - 「正直、ピンとこないんだよなぁ。要点だけ短くいきましょう。」
- ポイント: 第一声で **必ず用件**（事業承継・退職金など）を含める。名乗りだけだと山田が「で、ご用件は？」と聞き返すフェーズに留まる。

### T2: 3 論点で要点提示（relevance → pointExplanation）

```
はい、要点だけ申し上げます。見るのは3つで、自社株を渡す時の税負担、社長の退職金、社長に万一があった時の運転資金です。まず自社株の評価額は税理士さんから聞いていますか。
```

- 期待する山田の返答（pointExplanation 候補）:
  - 「うーん、自社株評価のことは、税理士さんに任せてるからなぁ。あんまり分かってないですね。」
  - 「なるほど、要点は3つね。ただ、税理士さんに確認しないと、こちらでは即答できないですね。」
- 判定キーワード: 「自社株」「退職金」「運転資金」「万一」のうち 2 つ以上で pointExplanation 確定。

### 【ここで営業部長に相談 Q1（任意）】

```
税理士に確認すると言われた。どう繋ぐ？
```

- 期待する助言（taxAccountant ステージの hint）

### T3: 税理士領域と保険領域を切り分け（pointExplanation → taxAccountant）

```
もちろん税理士さんへの確認が前提です。その前に、保険で備えられる部分だけ整理させてください。自社株の評価額と退職金の準備は、今どこまで把握されていますか。
```

- 期待する山田の返答（taxAccountant 候補。本音が一段にじむ）:
  - 「まあ、税理士さんへの確認は前提ですよ。ただ、息子のこともあるしねぇ…。」
  - 「整理してくれるのはありがたいんですが、正直、相続税のこと考えると胃が痛いですよ。」

### 【ここで営業部長に相談 Q2（任意）】

```
息子について深掘りしたい
```

- 期待する助言（taxAccountant の example セリフ：踏み込み用）

### T4: 息子・相続を深掘り（taxAccountant → hiddenConcern）

```
ご家族のお気持ち、よく分かります。長男さんに継がせる前提でいくと、自社株評価と相続税の試算が一番効くんですが、そこは数字を確認されていますか。
```

- 期待する山田の返答（hiddenConcern 候補。本音が漏れる）:
  - 「息子に継がせるのは決めてるんですが、税金で会社が傾いたら本末転倒でね。」
  - 「相続税のこと考えると、本当に夜眠れなくなる時があるんですよ。」

### T5: 無料診断面談を提案（hiddenConcern → softClose）

```
一度、御社の現状を整理する30分の無料診断面談をご提案させてください。自社株評価と退職金準備の現状をまとめて、税理士さんとの相談材料にしていただける形にします。
```

- 期待する山田の返答（softClose 候補）:
  - 「15分だけなら聞きますよ。売り込み前提じゃなく、要点からお願いします。」
  - 「面談ね。15分で要点だけまとめてもらえるなら、検討します。」

### T6: 日程を提示する（softClose → dateConfirm）

```
ありがとうございます。15分で、自社株評価と退職金準備の現状を整理した資料をお渡しできるように準備します。日程は来週前半でご都合いかがでしょうか。
```

- 期待する山田の返答（dateConfirm 候補。日程確定モードに切り替わる）:
  - 「来週の火曜なら、午前中は空いてますよ。11時からでいかがですか？」
  - 「そうですねぇ、来週の水曜の午後なら、30分ほど時間を作れます。14時からでよければ。」

### T7: 日程確定（dateConfirm → dateLocked）

```
ありがとうございます！では来週の火曜日11:00〜11:15でお願いします。当日は売り込みは一切しませんので、自社株評価の直近資料があればお手元にご準備いただけると助かります。
```

- 期待する山田の返答（dateLocked 候補）:
  - 「了解しました。当日は自社株評価の直近の資料を、こちらでも探しておきますよ。」
  - 「では、その時間でお待ちしています。よろしくお願いします。」
- 判定キーワード: 「曜日＋時刻」+ 「お願いします／では〜で」など確定句で dateLocked。

### 【ここで営業部長に相談 Q3（任意）】

```
クロージングのタイミングはどう判断する？
```

- 期待する助言（softClose の hint）

### 締めの操作

- **「💡 振り返り FB を受ける」ボタンを押下** → `getDemoCoachReview` から固定 3 部構成の講評が即座に表示される（LLM 呼ばないので途中切れ・記号崩れなし）
- 営業部長 AI が「■ 良かった点 / ■ 惜しかった点 / ■ 次の一手」で評価
- T1 と T7 の文面が引用される

## 営業部長相談（hint と example の使い分け）

サイドパネルでは「ヒント系」と「セリフ系」で挙動が違う：

| 質問パターン | 例 | 返答型 |
|---|---|---|
| **hint**（方針） | 「次は何を聞けばいい？」「どう進めれば？」 | `方針は、…` で始まる方針文 |
| **example**（セリフ） | 「なんて言えばいい？」「具体的なセリフは？」「息子について深掘りしたい」 | 営業が即送信できる短いセリフ本文 |

> 💡 demo モードでは質問文に含まれるキーワードから stage を自動推定します。会話が dateLocked まで進んでいても、「税理士に確認すると言われた」と聞けば taxAccountant の助言が返ります。

## TTS 事前チェックの観点

録画前に下記の返答候補を `/api/tts` で 1 件ずつ鳴らして、読みにくい箇所がないか確認:

- 「うちに何が関係するんです？」← 「？」の読み上げチェック
- 「自社株評価は税理士に任せてるからなぁ」← 「自社株評価（じしゃかびょうか／じしゃかひょうか）」のアクセントブレ
- 「3つ」「15分」「11時」← 数字読み上げ
- 「胃が痛い」← 「いがいたい」
- 「30分の無料診断面談」← 「30分」読み上げ

崩れがあれば demo-scenario.ts 側の文面を漢字 → ひらがな化 or 数字 → 漢数字化で正規化する。

## 録画手順サマリ

1. `ollama serve` 起動（demo モードでは Ollama 呼ばないが warmup fetch で叩くので念のため）
2. `npm run dev` → Chrome で `http://localhost:3001/roleplay?demo=1`
3. 画面録画ツール開始（システム音声＋マイク両方）
4. T1〜T7 を順に送信、途中で Q1〜Q3 を相談パネルに投げる
5. 「振り返り FB を受ける」で締め
6. 録画停止 → Drive アップ → 今井様へ共有
