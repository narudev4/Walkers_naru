# 台本: H2/H3見出しは必ず1スライド1見出し

## ルール
- 記事のH2見出し1つ → 1スライド（セクションタイトル）
- 記事のH3見出し1つ → 1スライド（解説スライド）
- **複数のH3見出しを1スライドにまとめるのは絶対NG**
- 「ポイント②と③をまとめる」「方法①と②を1枚に」のような統合は禁止

## 発生した問題
- 「ポイント②③: 情報発信と問い合わせ対応」として2つのH3を1スライドに統合してしまった
- 正しくは「ポイント②: 情報発信」と「ポイント③: 問い合わせ対応」で2スライドに分ける

## なぜ重要か
- 台本のスライド番号がPPTX生成・音声分割の下流工程すべてに影響する
- 1スライドに2見出し分の内容を詰めると、HeyGenでのスライド対応がずれる
- 元記事の構造を正確にトレースすることが品質の基盤

## 適用タイミング
- yt-script（台本生成）時の品質チェック項目として必ず確認
