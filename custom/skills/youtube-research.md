# YouTube動画リサーチ

トリガー: 「YouTube調べて」「動画リサーチ」「バズ動画」「YouTube トレンド」

## 概要
指定テーマでYouTubeのバズ動画を調査し、再生数・エンゲージメント・トレンド分析をレポートにまとめる。

## 実行フロー

### Phase 1: ヒアリング
以下をユーザーに確認する（未指定の項目のみ聞く）:

| 項目 | 必須 | デフォルト | 例 |
|------|------|-----------|-----|
| テーマ・キーワード | ✅ | - | 「AI開発」「バイブコーディング」 |
| 対象言語 | - | 日本語＋英語 | 「日本語のみ」「英語のみ」 |
| 期間 | - | 直近1ヶ月 | 「過去1週間」「過去3ヶ月」 |
| 件数 | - | TOP20 | 「TOP10」「TOP30」 |
| 地域 | - | JP | 「US」「グローバル」 |

### Phase 2: 動画検索（並列実行）
テーマから **3〜4パターンの検索クエリ** を生成し、YouTube MCP で並列検索する。

**クエリ生成のコツ:**
- メインKW + 関連語の組み合わせ（例: 「AI開発 エージェント」「Claude Code バイブコーディング」）
- 日本語KW と 英語KW の両方を検索
- `order: viewCount` + `recency` フィルターで再生数順に取得
- `regionCode` を指定して地域フィルタ
- 各クエリ `maxResults: 20` で十分な候補を確保

```
mcp__youtube__searchVideos:
  query: [生成したクエリ]
  maxResults: 20
  order: viewCount
  recency: pastMonth  # 期間に応じて変更
  regionCode: JP      # 地域に応じて変更
```

### Phase 3: 詳細データ取得
検索結果から **重複を除去** した videoId リストを作成し、`getVideoDetails` で一括取得する。

```
mcp__youtube__getVideoDetails:
  videoIds: [重複除去済みリスト]
```

取得するメトリクス:
- 再生数 (viewCount)
- 高評価数 (likeCount) → 高評価率 = likeCount / viewCount
- コメント数 (commentCount) → コメント率 = commentCount / viewCount
- 動画の長さ (duration)
- 公開日 (publishedAt)
- デフォルト言語 (defaultLanguage)

### Phase 4: フィルタリング・ランキング
1. **言語フィルタ**: `defaultLanguage` や チャンネル名・タイトルで日本語/英語を判定
2. **再生数でソート**: 降順
3. **指定件数に絞る**: TOP20 など
4. **翻訳動画の除外**: 海外動画の自動翻訳タイトルは除外（元言語と一致しないもの）

### Phase 5: レポート生成

以下の構成でレポートを生成する:

#### 5-1. ランキングテーブル
| # | タイトル | CH | 再生数 | 高評価率 | 公開日 |
で一覧表示。再生数は万単位で表記。

#### 5-2. 分析サマリー
以下の観点で分析を加える:

- **話題の中心**: 何のテーマが最も多いか、割合
- **よく出るチャンネル**: 複数本ランクインしているCHとその特徴
- **高エンゲージメント動画**: 高評価率TOP3（再生数×高評価率で影響力を評価）
- **バズるキーワード**: タイトルに頻出するパワーワード
- **Walkersへの示唆**: テーマに応じた事業活用の観点（コンテンツ企画・記事ネタなど）

### Phase 6: 保存

`output/trends/YYYY-MM-DD_youtube_[テーマ].md` に保存する。

```markdown

生成日: YYYY-MM-DD
対象期間: [期間]

|---|---------|-----|--------|---------|--------|
| 1 | **[タイトル]** | [CH名] | **[X.X万]** | [X.X%] | [M/D] |
| ... | ... | ... | ... | ... | ... |

## 分析サマリー

### 話題の中心
- [テーマ別の本数と割合]

### よく出るチャンネル
- **[CH名]**: [X本ランクイン。特徴]

### 高エンゲージメント動画 TOP3

「[KW1]」「[KW2]」「[KW3]」...
```

## ルール
- 再生数・高評価数などの数値は正確に表記する（YouTube APIの実データを使用）
- 高評価率は小数点1位まで表記
- 再生数は万単位（例: 68.8万）で読みやすく
- 翻訳タイトルの海外動画と日本語オリジナル動画は明確に区別する
- 検索クエリを工夫し、取りこぼしを減らす（最低3パターン並列検索）
- 分析は主観を排し、データに基づいた客観的な記述にする
