# 戦略分析チーム起動

トリガー: 「戦略分析」

## 概要
5エージェントが5フェーズで連携して戦略オプションを導出する。

## 利用するツール

| フェーズ | ツール | 用途 |
|---------|--------|------|
| 市場調査 | `WebSearch` | 市場規模・トレンド・競合情報を収集 |
| 市場調査 | `WebFetch` | 業界レポート・記事の詳細を取得 |
| 定量分析 | `google_sheets_read`（Google MCP） | 財務データ・KPIデータを取得 |
| 定量分析 | `google_drive_search`（Google MCP） | 関連スプレッドシート・資料を検索 |
| 内部情報 | `Glob` + `Read` | ローカルの戦略資料（`01_strategy/`）を確認 |
| 内部情報 | `gmail_search_messages`（マネージドコネクタ） | 関連するビジネスメールを検索 |
| 保存 | `Write` ツール | 最終レポートを `01_strategy/` に保存 |

## エージェント構成

| エージェント | 役割 |
|:-----------|:-----|
| 問いの設計 | 分析すべき問いをMECEに構造化 |
| 市場調査 | 市場規模・トレンド・競合を調査（`WebSearch` + `WebFetch`） |
| 定量分析 | 財務データ・KPIの分析・シナリオモデリング（`google_sheets_read` + ローカルデータ） |
| 戦略設計 | 調査結果を統合し、3つ以上の戦略オプションを策定 |
| 批判的レビュー | 戦略の弱点・リスク・隠れた代替案を指摘 |

## 実行フロー

1. **ヒアリング**: 分析テーマ・背景・制約条件を確認
2. **問いの設計**: 分析すべき問いをMECEに構造化
3. **調査（並列）**:
   - 市場調査: `WebSearch` で市場データ収集 + `WebFetch` で詳細取得
   - 定量分析: `google_sheets_read` で財務データ取得 + `Glob`+`Read` でローカル資料確認
4. **戦略設計**: 調査結果を統合し戦略オプションを策定
5. **批判的レビュー**: 弱点・リスク・代替案を指摘
6. **最終統合**: フィードバックを反映した最終レポートを生成

## 出力先
`01_strategy/YYYY-MM-DD_[テーマ]_strategy.md`
