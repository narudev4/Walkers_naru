# YouTube AI動画 制作マニュアル

> `/yt-produce` パイプラインの操作手順書。記事URLから完成動画のYouTube投稿まで。

---

## 全体フロー

```
記事URL
  ↓ [STEP 1] 🤖 記事スクレイピング
article.md
  ↓ [STEP 2] 🤖 台本生成
script.md
  ↓ 👤 台本確認・修正
  ↓
  ├── [STEP 3] 🤖 スライド生成 ──┐
  │                              │← 並列実行
  └── [STEP 4] 🤖 音声生成 ──────┘
slides.pptx + full.wav
  ↓ 👤 スライド＆音声確認
  ↓ [STEP 5] 🤖 音声分割 + チャプター生成
scenes/*.wav
  ↓ [STEP 6] 👤+🤖 HeyGen動画生成
video.mp4
  ↓ [STEP 7] 👤 YouTube投稿
完了！
```

| 区分 | 所要時間 |
|------|---------|
| 🤖 AI自動処理 | 約30分 |
| 👤 手動作業 | 約36分 |
| ⏳ HeyGen生成待ち | 2〜4時間（放置OK） |
| **実働合計** | **約1時間** |

| コスト項目 | 金額/本 |
|-----------|--------|
| ElevenLabs（約7,000文字） | 約210円 |
| HeyGen Avatar IV（約19分） | 約2,850円 |
| **合計** | **約3,060円** |

## 事前準備

### 必要なもの

- [ ] 元記事のURL
- [ ] ElevenLabs APIキー（`credentials/elevenlabs_api_key.txt`）
- [ ] HeyGenアカウント（https://app.heygen.com）
- [ ] YouTube Studioアクセス権
- [ ] サムネイル画像（外注）

### 起動コマンド

```
/yt-produce [記事URL]
```

URLなしで起動すると、URLまたはテーマをヒアリングされる。

---

## STEP 1: 記事スクレイピング 🤖自動

**やること**: なし（自動実行）

| 項目 | 内容 |
|------|------|
| 入力 | 記事URL |
| 出力 | `projects/{slug}-article.md` |
| 使用スキル | `/yt-scrape` |

WebFetchで記事を取得しMarkdown化する。失敗時はPlaywright MCPにフォールバック。

→ 完了後、自動でSTEP 2へ。

---

## STEP 2: 台本生成 🤖自動 → 👤確認

**やること**: 台本を読んでOKか判断する

| 項目 | 内容 |
|------|------|
| 入力 | `{slug}-article.md` |
| 出力 | `projects/{slug}-script.md` |
| 使用スキル | `/yt-script` |

記事の見出し構造に追従した台本を生成。概要欄テンプレート・チャプター・HeyGen対応表も含む。

### 👤 あなたの確認ポイント

1. **台本ファイルが自動で開かれる**ので内容を確認
2. 修正したい箇所があれば、その場で指示する
3. 問題なければ **「OK」** と入力

> ⚠ 「OK」を出すまで次のSTEPに進まない。何度でも修正できる。

---

## STEP 3+4: スライド＆音声生成 🤖並列自動 → 👤確認

**やること**: スライドと音声を確認する（2つ同時にチェック）

### STEP 3: スライド生成

| 項目 | 内容 |
|------|------|
| 入力 | `{slug}-script.md` |
| 出力 | `projects/{slug}-slides.pptx` |
| 使用スキル | `/yt-slides` |

### STEP 4: 音声生成（ElevenLabs）

| 項目 | 内容 |
|------|------|
| 入力 | `{slug}-script.md` |
| 出力 | `projects/{slug}-audio/full.wav` |
| 使用スキル | `/yt-voice` |

> 台本が5,000文字を超える場合、セクション境界で自動分割 → 複数APIコール → FFmpegで結合される。

### 👤 あなたの確認ポイント

#### スライド確認
- Keynoteで自動で開かれるので目視確認
- 修正があればその場で指示

#### 音声確認（重要！）

音声は複数チャンクに分割→結合されている。**チャンク結合点のテーブルが表示されるので、その前後を重点的に聴く。**

チェック項目:

- [ ] 数字の読み上げ: 「2700万円」「900万円」「300万円」が正しいか
- [ ] 分数: 「3分の1」が「13」になっていないか
- [ ] 範囲表現: 「0から1」「0から100」が正しいか
- [ ] 音声崩壊: 途中で音が壊れていないか
- [ ] 結合点: チャンクのつなぎ目で不自然な間や切れがないか

問題なければ **「OK」** と入力。

---

## STEP 5: 音声分割＋チャプター生成 🤖自動

**やること**: なし（自動実行）

| 項目 | 内容 |
|------|------|
| 入力 | `full.wav` + `{slug}-script.md` |
| 出力 | `projects/{slug}-audio/scenes/scene01〜{N}.wav` + CTA 8シーン |
| 使用ツール | Whisper medium → 台本冒頭フレーズで正確にカット |

### 処理内容

1. Whisperで文字起こし
2. 台本の各シーン冒頭フレーズをマッチングしてカット
3. CTA音声も8スライド分に自動分割
4. **STEP 5.5**: 各sceneのWAV秒数から累積タイムスタンプを計算し、台本の概要欄チャプターを**実測値で更新**

### 出力例

```
scenes/
├── scene01_title.wav      37.6秒  「皆様こんにちは...」
├── scene02_toc.wav        16.4秒  「本動画では...」
├── scene03_sec01.wav      ...
├── ...
├── scene{N+1}_cta1.wav    ...     CTA音声
└── scene{N+8}_cta8.wav    ...     CTA音声
```

→ 完了後、チャプター一覧がクリップボードにコピーされる。

---

## STEP 6: HeyGen動画生成 👤手動（最も作業が多い）

**やること**: HeyGenで動画を組み立てて生成する

### 手順1: PPTXアップロード

1. https://app.heygen.com を開く
2. 「Create Video」→ PPTXをアップロード
3. **⚠ 「スライドの内容を編集可能な要素としてインポート」を必ずOFFにする**
4. 「Use speaker notes as your script」を選択
5. ファイル: `projects/{slug}-slides.pptx`

### 手順2: 音声アップロード

**2通りの方法がある:**

| 方法 | やること |
|------|---------|
| 自動 | 「音声アップロードを自動化して」と指示 → Chrome MCPで実行 |
| 手動 | 各シーンの「音声をアップロード」から `scenes/scene01〜{N}.wav` を順番にアップ |

### 手順3: アバター設定

| 設定項目 | 値 |
|---------|-----|
| アバター | 鳳汰（背景リアル＆スーツ見えるver） |
| レイアウト | 円 |
| 半径 | 98px |
| ズーム | 139% |
| モーションエンジン | アバター IV |
| 適用 | 「既存のアバターを置き換え」→「選択」で全シーン適用 |

### 手順4: アバター位置調整

- **各シーンで**アバターを**右上端**にドラッグ
- ⚠ 「既存のアバターを置き換え」では位置がコピーされないため、全シーン手動調整が必要

### 手順5: 背景BGM追加

| 設定項目 | 値 |
|---------|-----|
| BGMジャンル | Corporate / Upbeat系 推奨 |
| **Volume** | **3%**（ナレーションが聞こえなくなるので必ず下げる） |
| **Loop music** | **ON**（動画全体をカバー） |

### 手順6: プレビュー確認

いくつかのシーンを再生して以下をチェック:

- [ ] スライドが正しく表示されている（ダブルクリックして確認）
- [ ] アバターが右上に配置されている
- [ ] 音声がスライドと一致している
- [ ] BGMが小さく流れている（ナレーションを邪魔していない）

### 手順7: 生成

1. 右上の「✓ 生成」ボタンをクリック
2. **Quality + 1080p** を選択
3. 生成開始 → **2〜4時間待ち（放置OK）**

→ 完成したら **「完成した」** とClaude Codeに入力。

---

## STEP 7: YouTube投稿 👤手動

**やること**: YouTube Studioにアップロードする

### 手順1: 動画アップロード

1. https://studio.youtube.com を開く
2. 「作成」→「動画をアップロード」
3. HeyGenからダウンロードした動画ファイルを選択

### 手順2: 概要欄設定

- Claude Codeが概要欄テキストをクリップボードにコピー済み
- **Ctrl+V**（Cmd+V）で貼り付け
- チャプターはSTEP 5.5で実測値に更新済み

### 手順3: サムネイルアップロード

- 外注で納品されたサムネイル画像をアップロード

### 手順4: 改変コンテンツにチェック（⚠ 必須）

1. 「詳細」タブの下部 →「改変されたコンテンツ」セクション
2. 「この動画はリアルに見えるように改変または合成されたコンテンツですか？」
3. → **「はい」にチェック**

> ⚠ AIアバター（HeyGen）使用のため**必須**。未チェックだとYouTubeポリシー違反の可能性あり。

### 手順5: 公開設定

1. まず **「非公開」** でアップロード
2. 動画を確認後、問題なければ **「公開」** に変更

→ 投稿完了したら **「完了」** とClaude Codeに入力。

## トラブルシューティング

| 問題 | 対処 |
|------|------|
| WebFetchで記事取得失敗 | Playwright MCPにフォールバック（自動） |
| ElevenLabs APIキーがない | `credentials/elevenlabs_api_key.txt` を確認。なければ取得して配置 |
| 台本が5,000文字超 | セクション境界で自動分割（対応済み） |
| CTA音声が崩壊 | CTA部分だけ再生成。テンプレート音声があればそれを使用 |
| Whisperの分割精度が低い | 全セグメント一覧が出力されるので、手動でカットポイントを調整 |
| スライド生成でPythonエラー | エラー修正して再実行（自動） |
| PPTXがKeynoteで開けない | bash heredoc方式で再生成を指示 |

