## 次にやること（ここから再開）

### 1. スライドと音声の確認（川岸さんに依頼）

**スライド確認:**
```bash
open projects/what-is-zapier/slides.pptx
```
- 全3認5枚の構成を目視確
- 特に使い方セクション（スライド22〜27）がSTEP毎に1枚ずつ分かれているか
- 修正が必要な場合は指示をもらう

**音声確認:**
```bash
open projects/what-is-zapier/audio/full.wav
```
以下のタイムスタンプを重点的に確認してもらう:

| リスク | タイムスタンプ | 内容 |
|--------|-------------|------|
| 低 | **1:22付近** | チャンク1末尾（導入終わり） |
| 低 | **2:26付近** | チャンク2末尾（Zapierとは終わり） |
| 低 | **4:37付近** | チャンク3末尾（4つの特徴終わり） |
| 低 | **6:24付近** | チャンク4末尾（4つの注意点終わり） |
| 低 | **7:14付近** | チャンク5末尾（料金プラン終わり） |
| 中 | **7:54付近** | チャンク6末尾→CTA接合部 |

CTA末尾の確認ポイント:
- 「2700万円」「900万円」「300万円」が正しく読まれているか
- 「3分の1」が「13」になっていないか
- 「0から1」「0から100」が正しいか

### 2. 確認OKが出たら → STEP 5実行

```
/yt-split-audio what-is-zapier
```
これで音声をシーン別に自動分割する。

### 3. STEP 5完了後 → STEP 6（HeyGen手動作業）の案内

パイプラインスキルが自動でHeyGenの手動手順を案内する。
もしスキル外で手動案内する場合は `/yt-heygen` を参照。

### 4. 以降はパイプラインの流れ通り

STEP 7（サムネイル） → STEP 8（YouTube投稿）と続く。
