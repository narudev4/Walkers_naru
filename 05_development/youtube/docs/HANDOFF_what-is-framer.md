## 次にやること

### 1. 川岸さんにスライドと音声の確認を依頼

スライドと音声はAIが自動生成したまま、川岸さんの目視・耳確認がまだです。
以下を川岸さんに伝えてください。

```
【スライド確認】
projects/what-is-framer/slides.pptx をKeynoteで開いて確認お願いします。

【音声確認】
projects/what-is-framer/audio/full.wav を再生して、
特に以下のタイムスタンプ付近でブツ切れがないか確認お願いします。

| タイムスタンプ | 内容 |
|-------------|------|
| 1:43付近 | チャンク1→2の結合点 |
| 3:11付近 | チャンク2→3の結合点 |
| 7:21付近 | チャンク3→4の結合点（1731字チャンク末尾・要注意） |
| 9:33付近 | チャンク4→5の結合点 |
| 10:44付近 | チャンク5→6の結合点 |
| 12:34付近 | チャンク6→7の結合点 |
| 13:41付近 | チャンク7→8の結合点 |
| 15:17付近 | 本編→CTAテンプレート接合点（要注意） |

CTA末尾の確認ポイント:
□ 「2700万円」「900万円」「300万円」が正しく読まれているか
□ 「3分の1」が「13」になっていないか
□ 「0から1」「0から100」が正しいか
```

### 2. OKが出たら STEP 5 を実行

川岸さんからOKが出たら、以下のコマンドで音声分割スキルを起動してください。

```
/yt-split-audio what-is-framer
```

このスキルが自動でやること:
- Whisper mediumで文字起こし
- 台本の冒頭フレーズで正確にカット
- CTA音声も8スライド分に自動分割
- `audio/scenes/` にscene01〜scene{N}.wav + CTA分割WAVを保存

### 3. STEP 5.5: 概要欄チャプター生成

STEP 5完了後、scenes/*.wavの秒数から累積タイムスタンプを計算し、
台本（script.md）の概要欄チャプターを実測値で更新する。
（パイプラインスキルの手順書 `/yt-produce` に詳細あり）

### 4. STEP 6: HeyGen動画生成（手動作業が最も多い）

手順概要（詳細は `/yt-produce` スキルのSTEP 6参照）:

1. PPTXをHeyGenにアップロード
   - 「スライドの内容を編集可能な要素としてインポート」を**必ずOFF**
   - 「Use speaker notes as your script」を選択
2. 音声をシーン別にアップロード（scenes/scene01〜）
3. アバター設定
   - アバター: 山口鳳汰(背景リアル&スーツ見えるver)
   - レイアウト: 円 / 半径: 98px / ズーム: 139%
   - モーションエンジン: アバター IV
4. アバター位置を各シーンで右上端にドラッグ
5. **背景BGM: Volume 3% ・ Loop ON（必須）**
6. プレビュー確認 → 生成ボタン（Quality + 1080p）

### 5. STEP 7: サムネイル生成

```
/yt-thumbnail what-is-framer
```

### 6. STEP 8: YouTube投稿（手動）

概要欄テンプレートは台本（script.md）内に記載済み。
チャプターのタイムスタンプはSTEP 5.5で実測値に更新済みのものを使う。

## 注意事項（過去の事故から学んだルール）

- **CTA音声は毎回生成しない**: `_shared/templates/cta_audio_pcm.wav` を使う
- **cta_audio.wav は使用禁止**: 中身がMP3で結合に失敗する
- **ffmpeg結合は filter_complex concat 必須**: `concat -c copy` は音が途切れる
- **python-pptxでshadow禁止**: Keynoteが破損する
- **スピーカーノートは追加しない**: Keynote非互換
- **HeyGen BGM必須**: Volume 3% / Loop ON を生成前に設定
