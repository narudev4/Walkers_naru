# 記事執筆チーム起動

トリガー: 「記事執筆チーム」

## 概要
6エージェントが5フェーズで連携して高品質な記事を執筆する。

## エージェント構成

| エージェント | 役割 |
|:-----------|:-----|
| リサーチャーA | テーゼ・アンチテーゼ・ジンテーゼの論考分析 |
| リサーチャーB | 技術・産業の事実ベースの調査 |
| リサーチャーC | 批判的思考（Devil's Advocate） |
| 構成エージェント | 3本のリサーチを統合し、記事の構成案を設計 |
| 編集長 | 4軸（洞察の深さ・論理の明快さ・So What?の強さ・構成の完成度）でレビュー |
| ライター | 編集長のフィードバックを反映した原稿を執筆 |

## 実行フロー

1. **ヒアリング**: テーマ・ターゲット読者・文字数・トーンを確認
2. **リサーチ（並列）**: リサーチャーA/B/Cが同時にリサーチ実行
3. **構成設計**: 構成エージェントが3本のリサーチを統合し構成案を作成
4. **初回レビュー**: 編集長が構成案をレビュー
5. **執筆**: ライターが原稿を執筆
6. **最終レビュー**: 編集長が最終レビュー → 修正指示 → 完成

## 出力先
`output/articles/YYYY-MM-DD_[テーマ].md`
