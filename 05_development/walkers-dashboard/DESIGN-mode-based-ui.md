# ダッシュボード モード別UI設計書

**作成日**: 2026-03-20
**ステータス**: 詳細要件定義（レビュー待ち）
**関連**: ARCHITECTURE-v4.md セクション10

---

## 1. 課題

現状のダッシュボードは**全タブが常に表示**され、タブ内のUIも**モードに関係なく同一**。

問題点:
- 個人PCで「マシン管理」「セッション」が目に入るが使わない
- 共有マシンで「パイプライン」「プロジェクト」が並ぶが触らない
- 同じエージェントタブでも、個人PCと共有マシンで**見たい情報が違う**
- 同じスキルタブでも、個人PCでは**編集**、共有マシンでは**閲覧のみ**が正しい

→ タブの出し分け**だけでなく**、タブ内のUI/操作権限もモードに応じて変えるべき。

---

## 2. 運用モード定義

| モード | 条件 | 典型的な利用者 |
|--------|------|-------------|
| **個人PC** | `sharedMachineMode.enabled === false` | メンバー本人（自分のPCで業務） |
| **共有マシン** | `sharedMachineMode.enabled === true` | 管理者（常時稼働サーバー監視） |

※ `read_only`モードは別概念（共有マシンモードとは独立）。将来的に「他メンバーが共有マシンのダッシュボードを閲覧する」ケースで使う。

---

## 3. タブレベルの設計

### 3.1 タブ表示マトリクス

| タブ | 個人PC | 共有マシン | 理由 |
|------|--------|-----------|------|
| スキル | **表示** | 折りたたみ | 共有マシンでスキル編集は稀 |
| メモリ | **表示** | 折りたたみ | 共有マシンの記憶を直接編集する場面は稀 |
| パイプライン | **表示** | **非表示** | 営業は完全に個人業務 |
| プロジェクト | **表示** | **非表示** | 案件管理は個人業務 |
| 出力ファイル | **表示** | 折りたたみ | 共有マシンのoutput確認は稀 |
| Skill Hub | **表示** | **表示** | 共有レイヤー（両方で使う） |
| エージェント | **表示** | **表示（メイン）** | 共有マシンの核心機能 |
| セッション | 折りたたみ | **表示** | リモートチャット履歴は共有マシン側の関心事 |
| マシン | 折りたたみ | **表示** | マシン管理は共有マシンの関心事 |
| ギャラリー | **表示** | **表示** | 共有レイヤー（両方で使う） |
| 設定 | **表示** | **表示** | 常に必要 |

### 3.2 ナビゲーション表示

**個人PCモード:**
```
メイン: スキル | メモリ | パイプライン | プロジェクト | 出力ファイル | Skill Hub | エージェント | ギャラリー | 設定
展開:   [▾ その他] → セッション | マシン
```

**共有マシンモード:**
```
メイン: エージェント | セッション | マシン | Skill Hub | ギャラリー | 設定
展開:   [▾ その他] → スキル | メモリ | 出力ファイル
```

### 3.3 デフォルトタブ

| モード | デフォルト | 理由 |
|--------|-----------|------|
| 個人PC | `#skills` | スキル確認・編集が最頻出 |
| 共有マシン | `#agents` | cron監視がメイン業務 |

## 4. タブ内UIの差分設計（核心）

### 4.1 スキルタブ

| 要素 | 個人PC | 共有マシン |
|------|--------|-----------|
| カード一覧 | ● 表示 | ● 表示（同じ） |
| カードクリック→編集モーダル | ● **編集可能** | ● **閲覧のみ**（textarea を readonly に） |
| 「+ 新規スキル」ボタン | ● 表示 | ✕ 非表示 |
| 「削除」ボタン | ● 表示 | ✕ 非表示 |
| 「Skill Hubに掲載」ボタン | ● 表示 | ✕ 非表示（掲載は個人PCから行う） |
| 検索バー | ● 表示 | ● 表示 |

**理由**: 共有マシンのスキルを管理者が閲覧して確認することはあるが、編集するのは個人PCの仕事。共有マシンでスキルを弄ると、個人YourAIとの乖離が生まれる。

---

### 4.2 メモリタブ

| 要素 | 個人PC | 共有マシン |
|------|--------|-----------|
| メモリカード一覧 | ● 表示 | ● 表示 |
| カードクリック→編集モーダル | ● **編集可能** | ● **閲覧のみ** |

**理由**: 共有マシンの記憶（facts等）はcronのコンテキスト情報として参考にはなるが、編集はしない。

---

### 4.3 パイプラインタブ

| 要素 | 個人PC | 共有マシン |
|------|--------|-----------|
| メトリクスカード | ● 表示 | — タブ自体非表示 |
| ドーナツチャート | ● 表示 | — |
| 要対応アクションテーブル | ● 表示 | — |
| カンバンボード | ● 表示 | — |

**理由**: 営業パイプラインは個人業務。共有マシンには案件データ自体がない。

---

### 4.4 プロジェクトタブ

| 要素 | 個人PC | 共有マシン |
|------|--------|-----------|
| プロジェクトカード一覧 | ● 表示 | — タブ自体非表示 |

**理由**: 03_projects/ は個人YourAIのデータ。共有マシンにはプロジェクトフォルダがない（あっても共有マシン上の案件ではない）。

---

### 4.5 出力ファイルタブ

| 要素 | 個人PC | 共有マシン |
|------|--------|-----------|
| ファイル一覧 | ● 表示 | ● 表示（折りたたみ内） |

**理由**: 共有マシンでもoutput/に生成物が溜まるので確認できた方が良いが、メイン動線ではない。

---

### 4.6 Skill Hub タブ

| 要素 | 個人PC | 共有マシン |
|------|--------|-----------|
| スキルカード一覧 | ● 表示 | ● 表示（同じ） |
| 検索・カテゴリフィルタ | ● 表示 | ● 表示 |
| プレビューモーダル | ● 表示 | ● 表示 |
| 「インストール」ボタン | ● **表示** | ✕ **非表示** |
| 「取り下げ」ボタン | ● 表示 | ● 表示（管理権限として） |

**理由**: インストール先は各個人YourAIなので、共有マシンからインストールしても意味がない。取り下げは共有レイヤーの管理操作なので共有マシンからも可能。

---

### 4.7 エージェントタブ（最大の差分）

| 要素 | 個人PC | 共有マシン |
|------|--------|-----------|
| **モードバナー** | 「💻 個人モード」（グレー） | 「🖥 共有マシンとして稼働中」（緑） |
| **メトリクスカード** | サブAgent数、cron数、記憶件数 | サブAgent数、cron数、記憶件数 + **稼働時間**、**Gateway接続状態** |
| サブエージェントカード | ● 表示 | ● 表示 |
| 手動実行ボタン | ● 表示 | ● 表示 |
| cron切り替え | ● 表示 | ● 表示 |
| 編集ボタン | ● 表示 | ● 表示 |
| 削除ボタン | ● 表示 | ● 表示 |
| **cron信頼性インジケータ** | 「⚠ PC閉じたら停止」（警告色） | 「✅ 常時稼働」（緑色） |
| **実行ログ** | 最新5件 | **最新20件** + 自動リフレッシュ（30秒ごと） |
| **Gateway状態パネル** | ✕ 非表示 | ● **表示**: 接続中/切断、ポーリング間隔、最終コマンド受信時刻 |
| **Google Chat Bot状態** | ✕ 非表示 | ● **表示**: サービスアカウント設定済み/未設定、最終通知送信時刻 |
| **「▶▶ 全実行」ボタン** | ● 表示 | ● 表示 |
| **システムヘルスサマリー** | ✕ 非表示 | ● **表示**: サーバー起動時刻、メモリ使用量、処理コマンド数 |

**理由**: 共有マシンではエージェントタブが「コントロールセンター」。cron監視、Gateway状態、Google Chat連携状態をここで一望したい。個人PCではサブエージェントの管理が主で、インフラ状態は不要。

## 5. ヘッダーの改善

### 5.1 現状

```
[W] Walkers Dashboard — desktop-2h2gh54   [スキル] [メモリ] [パイプライン] ...   [58s] [↻] [◗] [●]
```

### 5.2 提案

**個人PC:**
```
[W] Walkers Dashboard — desktop-2h2gh54   [スキル] [メモリ] ...  [▾その他]   [58s] [↻] [◗] [●]
                                                                              💻 個人
```

**共有マシン:**
```
[W] Walkers Dashboard — Full-Windows      [エージェント] [セッション] ...  [▾その他]   [38s] [↻] [◗] [●]
                                                                                     🖥 共有マシン
```

変更点:
- 共有マシンモード時はmachineIdではなく**machineName**を表示
- モードバッジをヘッダー右に常時表示
- タブが「メイン」と「その他」に分離

## 6. 実装方針

### 6.1 モード取得

```javascript
// 起動時に1回取得してStateに保存
const smMode = await DataLayer.getSharedMachineMode();
State.set('sharedMachineMode', smMode);
const isShared = smMode && smMode.enabled;
```

### 6.2 タブ定義

```javascript
const TAB_CONFIG = {
  personal: {
    main: ['skills', 'memory', 'pipeline', 'projects', 'outputs', 'skillhub', 'agents', 'gallery', 'settings'],
    more: ['sessions', 'machines'],
    default: 'skills',
  },
  shared: {
    main: ['agents', 'sessions', 'machines', 'skillhub', 'gallery', 'settings'],
    more: ['skills', 'memory', 'outputs'],
    default: 'agents',
  }
};
```

### 6.3 タブ内UIの分岐

各render関数内で `isShared` をチェック:

```javascript
function renderSkills(skills) {
  const isShared = State.get('sharedMachineMode')?.enabled;
  // ...
  if (!isShared) {
    // 「+ 新規スキル」ボタン、「削除」ボタン表示
  }
  // Editor.open() 呼び出し時: isShared なら readonly=true
}
```

### 6.4 影響範囲

| ファイル | 変更内容 |
|---------|---------|
| `index.html` | Router.init() でモード取得 → タブ定義切替 |
| `index.html` | ヘッダーにモードバッジ追加 |
| `index.html` | renderSkills: 編集制限 |
| `index.html` | renderMemory: 編集制限 |
| `index.html` | renderAgents: Gateway/ChatBot状態パネル追加 |
| `index.html` | renderSettings: セクション順序変更 |
| `server.py` | `/api/health` 新設（稼働時間・処理コマンド数・Gateway状態） |

## 7. 実装優先度

| 優先度 | 項目 | 工数 | 効果 |
|--------|------|------|------|
| **P0** | デフォルトタブの切替（共有マシン→#agents） | 5分 | 即効性あり |
